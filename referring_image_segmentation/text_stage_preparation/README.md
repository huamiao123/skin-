## 数据方向

默认先沿当前皮肤病灶方向核查真实文本资源，方向偏好已向用户询问；第六轮训练不依赖该回答。若选择通用指代任务，可准备 RefCOCO 标准划分。若保留医学方向，需要先落实真实表达的标注来源、目标定义和许可。

没有合格文本时可以先完成纯视觉实验，不能将统一提示“分割病灶”包装成语言指代理解实验。若仅有单目标图和属性描述，应明确任务为文本条件分割，并承认这种数据可能无法区分模型是否在用文本选择目标。

候选的图文接口及验证规范见 [DATA_PROTOCOL.md](DATA_PROTOCOL.md)。这是数据准备草案，数据集及split确定后、首次图文训练前另行冻结正式训练协议；不会直接照搬ISIC的300epochs/batch64到不同规模的数据集。
