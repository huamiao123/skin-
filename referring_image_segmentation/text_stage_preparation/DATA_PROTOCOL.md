# 图文数据接口与评价草案

状态：准备草案，2026-10-17；未启动图文训练，未完成数据集选择。第六轮视觉复验独立执行。

## 统一样本接口

使用JSONL，每行包含以下字段；路径相对于清单所在目录或使用可解析绝对路径。

| 字段 | 说明 |
|---|---|
| sample_id | 唯一表达与目标组合ID |
| image_id / image_path | 图像标识与原图 |
| target_id / mask_path | 表达对应目标与原尺寸二值掩码 |
| expression | 非空自然语言指代表达 |
| split | train / val / test；遵守数据源官方划分或事先固定分组划分 |
| dataset / dataset_version / source | 数据来源、版本、可追溯文档 |
| text_source | human / synthetic / template；自动生成的不能标为人工 |
| annotation_method | 文本如何得到、是否使用GT/诊断或其他额外信息 |
| available_at_inference | 该描述所用信息在拟定推理场景是否实际可用 |
| patient_id / lesion_id / group_id | 可用的医学分组标识；缺失保留null，不能伪造 |

同图多表达、同图多目标应分别保留。不同表达可能描述同一目标，目标不同才预期mask随表达切换。统计图数、目标数、表达数和三者关系，不能把多表达数当成独立图数。

## 数据审计

首次训练前固定清单并保存SHA256；检查文件存在、图mask尺寸和解码、目标标识一致、标签二值、文本非空/来源、样本ID唯一。检查图像内容重复、近重复及患者/病灶分组跨split；报告无法验证的分组缺失。

文本在划分之后按固定流程收集，测试标签不能用于生成推理输入。若研究确需GT派生或诊断辅助文本，将其单独标记为额外监督条件，不能据此声称常规图像+自然文本输入的泛化成绩。固定模板仅用于消融或接口测试。

旧ISIC/IMA/PH2数据的历史使用与重叠需重新对照当前1886/808数据的内容哈希。现有旧重叠报告可用于定位问题，不能取代本项目当前manifest审计。测试集用于最终锁定模型的评估，不能据测试结果继续选结构/阈值/checkpoint。

## 初版模型接口

Image → DINOv3-S/16 → Adapter → 原Swin Pixel Decoder → V。
Text → 一个固定版本文本Encoder → 可训练Text Adapter → U。
Mask logits = U V^T；两侧投影维度相同。现有Swin的1通道readout需在新阶段显式替换为像素特征投影；历史模型源码保持只读。

冻结视觉和文本预训练Encoder作为第一版，训练Adapters、Pixel Decoder及对齐投影；DINOv3与文本空间不假定天然对齐。模型版本、文本tokenizer/截断长度、训练分辨率、batch、学习率和预算在数据集选定并完成显存/吞吐测量后冻结。损失先保持简单，图文机制、VMamba和新的损失不同时修改。

视觉候选由第六轮结果决定。先验证DINO单分支的文本条件baseline，再在同一数据和图文接口下加入经过确认的VMamba候选；视觉ISIC成绩不能直接预测通用指代数据的表现。

## 文本有效性与评价

- 正确表达：按真实表达评估对应目标。
- 固定文本/无文本：推理时替换可作为输入干预；若要归因文本收益，另有从头训练的无文本或固定文本容量对照。干预导致分布偏移，不等同于公平训练消融。
- 同图不同目标表达：输入真实的另一目标表达并评估那个目标的GT，检验是否随文本切换目标。只有存在真实多目标标注时才做，不能构造假目标。
- 打乱表达：仅作诊断。若表达来自另一图且本图无对应目标，没有合法目标GT，不能直接按普通样本排名或误称模型应该输出空mask；无目标能力需要明确训练/评价协议。
- 属性、位置、关系、困难表达分组须有独立标注或预定义规则，不从GT误差事后杜撰语义类别。

继续同时报告macro/pooled Dice、IoU、Precision/Recall、Prec@.5/.6/.7/.8/.9、Boundary F1和HD95（像素与图像对角线归一化）。ISIC另报告Threshold Jaccard；通用指代benchmark不把ISIC特有指标作为主排名。

正式协议要确定官方原尺寸或固定网格的评估方式，逐表达/逐目标/逐图聚合，阈值、边界容差、空mask规则和checkpoint选择；不可把ISIC256网格成绩直接与原图评估比较。多表达的区间估计应至少按图像聚类，患者标识可用时考虑患者层级，避免将同图表达当作独立图。

记录正确文本与干预的配对预测，报告完整Encoder+Decoder+Text推理延迟以及文本缓存条件。最终判断文本是否实际影响目标选择，而不仅是增加参数后的总体分数变化。
