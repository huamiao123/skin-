# Stage 20–21 实验归档说明

## 训练与结果

全部模型使用冻结的 ImageNet 预训练 MambaVision-S、ISIC2018 历史划分（1886 训练、808 开发验证）、256×256 输入、seed 42、300 epochs、9000 次更新；每组统一以最高验证逐图平均 Dice 选择最佳权重。开发验证集参与选模和反复探索，不是独立测试。

| 训练模型 | 最佳轮 | 逐图平均 Dice | 最佳权重 |
|---|---:|---:|---|
| MambaVision + Swin 配对基线 | 127 | 88.338% | [best_dice.pth](../stage20_decoder_fusion_seed42/results/paired_baseline/best_dice.pth) |
| MambaVision + 简单门控 | 32 | 88.153% | [best_dice.pth](../stage20_decoder_fusion_seed42/results/gate_only/best_dice.pth) |
| MambaVision + AXIS-Bridge | 159 | 88.440% | [best_dice.pth](../stage20_decoder_fusion_seed42/results/axis_bridge/best_dice.pth) |
| MambaVision + SegMAN Decoder 适配版 | 105 | 88.094% | [best_dice.pth](../stage20_decoder_fusion_seed42/segman_adaptation/results/best_dice.pth) |
| MambaVision + 部分 Swin + HGM BMD 适配版 | 116 | 88.239% | [best_dice.pth](../stage21_hgm_bmd_seed42/results/best_dice.pth) |

其中 HGM 的 Mamba 层以 FP32 运行，其余部分使用 BF16 autocast；SegMAN 使用框架及扫描内核适配。完整训练参数、指标口径、逐图结果及局限见各阶段报告。上述模型及参数规模不同，单 seed 差异不能当作稳定排名。HEDS、SegMAN 和 HGM 皆为局部模块或解码器适配，不等于完整论文复现。

## 归档范围与恢复

保留自己的实验源码、固定协议、日志、数值图、完整训练曲线、逐图数值、三类 checkpoint 的指标，以及每个模型的 **best_dice** 探针权重。这些权重不含 MambaVision 预训练 backbone，用户须自行按项目指引取得骨干和 ISIC 数据。`latest`、`best_loss`、`last` 与 smoke 的模型文件及优化器状态没有发布；本归档不能直接用于断点续训。stage14–19 此前未上传的数值 smoke 审计记录也一并存档，其结果不属于正式训练成绩。

上游第三方源码快照没有重新分发。运行 `python referring_image_segmentation/publication/restore_stage20_21_references.py` 可从官方固定 commit 获取，脚本逐文件校验原始 SHA256 且不会覆盖内容不匹配的文件；使用前请检查上游授权。另需按已有阶段文档准备合适的 PyTorch/CUDA、Mamba 扩展与预训练 backbone。原始图像、第三方文本和逐像素预测不进入本仓库。

运行 `python referring_image_segmentation/publication/verify_stage20_21.py`，可离线核对归档文件哈希、五个模型的 300 轮状态及 808 张逐图 Dice 的聚合；这不会重新训练或对原始图像推理。
