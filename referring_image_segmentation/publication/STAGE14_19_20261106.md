## 最佳权重和校验

12 个文件的相对路径、SHA256、字节大小、模型、epoch 和验证指标记录在 [stage14_19_checkpoint_manifest.json](stage14_19_checkpoint_manifest.json)。这些 checkpoint 包含 Adapter、Decoder 和相应区域模块等非骨干参数，不包含冻结的 NVIDIA、DINOv3 或 VMamba 预训练骨干；其中可能保留模块内未使用的冻结参数，不能将其直接当成完整模型权重。未提供优化器、随机状态和调度器，不能用这些最佳权重无损续训。

从仓库根目录检查发布文件的 SHA256：

```bash
python referring_image_segmentation/publication/verify_stage14_19.py
```

第十九轮只使用最佳 checkpoint 的重新评估入口：

```bash
python referring_image_segmentation/publication/evaluate_stage19_best.py
```

该命令需要 CUDA 与 BF16、原数据和正确的预训练骨干、历史运行依赖；可指定 `--project /path/to/referring_image_segmentation`。不支持 BF16 的 CUDA GPU 可使用 `--precision fp32 --batch 8` 做兼容性诊断，但这不等同历史 BF16 评价。`--strict` 要求与历史汇总像素计数完全一致，跨精度、GPU 或依赖版本可能有数值差异。归档中的 `validation.json` 是历史实验结果，不代表新环境已重新跑通。

2026-11-06 在 RTX 2080 Ti 上使用 FP32、batch 8 重新加载两组最佳权重并通过数据清单检查：原顺序组 / 区域扫描组验证 Macro Dice 分别为 88.274% / 88.583%。它们与 RTX 3080 的历史 BF16 结果不逐像素一致，作为[兼容性验证](stage19_fp32_compatibility_20261106.json)，不替换原先按 BF16 选模和报告的结果。

## 数据、依赖和限制

ISIC 图像、原始掩码、含原图的病例拼图、逐像素概率和预测掩码不在本仓库；原实验数据清单位于 `stage1_visual/data_manifest.json`。该旧开发划分为 1886 训练 / 808 验证，无独立测试集，患者级分离尚未核验。特征诊断仅公开数值、源码和文字，不公开病例图片。

需要单独取得 NVIDIA 官方 [MambaVision-S-1K](https://huggingface.co/nvidia/MambaVision-S-1K) 预训练权重；冻结的修订为 `e4f9ea93877fba6f1e2d231fd0f0a391368ad895`，权重 SHA256 为 `006af39903f2d88c5b455431d087d0fcbf5d5932114aef52542c0d2f0b1ec180`。源码及其 [NVIDIA Source Code License-NC](../stage14_mambavision_s_isic2018_seed42/official/hf/LICENSE) 在此归档，使用和分发须遵守对应非商业限制。HiRAM 上游版权及 [CC BY-NC 4.0 许可](../stage16_hiram_dual_seed42/vendor_hiram/LICENSE) 随上游代码保存；来源和提交见 stage16 源码及协议。

原环境还依赖 `mamba-ssm` 1.2.2 的 CUDA 扩展、PyTorch 2.2.2+cu121、timm 1.0.22、Transformers 4.44.2；固定 wheel 地址和 SHA 见 `stage14.../official/mamba_wheel.json`。第十五轮另外需要固定版本的 VMamba 源码，具体身份见其 `routing_preflight.json`；原机使用的 stage15 `official` 和 `runtime` 链接指向 stage14，克隆后需自行建立对应链接。所有外部依赖需按其许可获取。

历史启动器会检查先前源码、路径、smoke 状态及一些未发布的逐像素预测，不能直接当作克隆后的一键复跑命令。路径与来源应在新实验中重新记录，不要覆盖历史文件。stage17 的部分旧概率及 mask 文件在本地发现稀疏空洞；相关结果通过重新推理与 808 张逐图像素计数复核，详见诊断报告。该问题与本次发布的最佳 checkpoint 不同；checkpoint 已成功重新加载。
