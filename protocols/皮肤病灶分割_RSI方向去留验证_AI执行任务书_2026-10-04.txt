5. 最关键实现：teacher固定，student tail独立
======================================================================

原代码不能直接支持U组：
  rsi.train/rsi.train_objective的B/D阶段仅训练message。
  ControlledModel.set_stage/train会把原cnn/tail设为冻结组件。
  forward_pair原z0和z1共享一个tail，tail解冻后会导致参照漂移。
  export_actions只实现消息feature缩放，不实现完整更新logit插值。
  train_stage会mirror到PROJECT/runs，prepare_q会写B目录；不能把旧存档
  路径直接传给这些有写操作的接口。新runner统一写新实验目录。

因此，在实验副本中新建明确的student-tail变体和相应runner/exporter；
不能只改requires_grad后沿用原训练/导出接口并宣布U实验完成。

推荐省计算实现：
  保留B的CNN encoder/prefix、原reference tail、Transformer和aux全固定；
  student_tail=deepcopy(B的reference tail)；
  message=deepcopy(B的已训练message)。
student_tail与reference_tail的参数storage必须不共享。

每个增强训练batch的前向：

  with no_grad():
      f8,c4 = frozen_CNN_features(同一个增强后的RGB)
      z_ref = frozen_reference_tail(f8,c4)
      if group != U-NoMessage:
          t16 = frozen_Transformer(同一个增强后的RGB)

  if group == U-NoMessage:
      M = 0
  else:
      M = trainable_message(f8,t16,原context_token_valid(pixel_valid))

  z_on = student_tail(f8+M,c4)
  按第6节计算每参考损失。

冻结student tail的F组，z_on路径仍需保留对message输入的梯度。
不能在student_tail前向整体使用no_grad，否则F组message学不到。
U组中frozen features可以no_grad，student_tail/message必须可导。

teacher包括参数与buffers，永远eval、requires_grad=False；所有冻结编码器
也保持eval。训练mode切换、evaluate、gradient_diagnostic之后均再验收。
每轮teacher hash和固定FP32 teacher输出不得漂移。

完整teacher应等于B里的真实CNN anchor；B阶段未改变它。它不是新tail
下的alpha0输出，也不是teacher与student参数共享后的detach结果。

可额外记录z_off_current=student_tail(f8,c4)：
  总更新收益：Dice(z_on)-Dice(z_ref)。
  同tail开关变化：Dice(z_on)-Dice(z_off_current)。
  off输出变化：Dice(z_off_current)-Dice(z_ref)。
U组的tail若只在on条件训练，off可能是未受训练支持的状态；第二项
只作诊断，不能当可信anchor，更不能由它单独证明异构特征有害。

6. 目标函数：保持原目标，不临时加入新损失
======================================================================

z形状[B,1,H,W]；参考mask形状[B,R,1,H,W]；present形状[B,R]。
沿用rsi/objectives.py的FP32有效像素与present处理，smooth=1e-6。

ell_ir = 0.5*BCE(z_i,y_ir) + 0.5*(1-SoftDice(z_i,y_ir))。
ell_ref_ir = 对同一增强图、同一参考与有效区域计算的固定teacher损失。

L_seg = mean_i(mean_{present r}(ell_ir))。
L_RSI = L_seg + 3*mean_i(mean_{present r}(relu(ell_ir-ell_ref_ir)))。
epsilon_L=0。

F-Mean/U-Mean/U-NoMessage只用L_seg；F-RSI/U-RSI用L_RSI。
teacher loss detach，risk项不能detach，均在autocast之外用FP32计算。
不要先平均参考mask；不要先平均参考loss再relu；不要按参考总数给图像
不同权重；不要把BCE/SoftDice比重、epsilon_L或λ一起修改。

本轮不使用AbsHard、不需要新增q估计、不追加KL、边界、门控或保收益loss。
可以记录梯度，不把诊断项加入训练目标。

9. 必做强对照：完整更新缩放与训练侧等幅控制
======================================================================

U组训练了tail，仅对feature消息乘α已经不能恢复固定teacher。
所以必须对选中U-Mean生成完整更新logit插值：

  Delta_mean = z_Umean - z_ref。
  z_alpha = z_ref + alpha*Delta_mean。
  alpha固定为0、1/3、2/3、1；四点全部展示。

它与旧feature Fixed-Shrink分列，不把两种运算混写。
插值在恢复原尺寸前的canonical logits上做，随后走相同恢复/阈值流程。
不要只平均二值mask或概率后还称logit插值。
不生成中间新α网格，不为每张验证图用GT选择α。
四点的开发曲线/包络可以描述，不能将其中验证最优α称独立测试结果。

另做一个预先指定的主要等幅控制，不使用任何GT拟合强度：
在1471张canonical train图、同一选中U-Mean和U-RSI checkpoint上，
逐图只使用预测和pixel_valid计算：

  S_mean = mean_i(mean_valid_pixels((z_Umean-z_ref)^2))。
  S_rsi  = mean_i(mean_valid_pixels((z_Ursi-z_ref)^2))。
  alpha_RMS_raw = sqrt(S_rsi/S_mean)。
  alpha_RMS = clip(alpha_RMS_raw,0,1)。
  z_RMS = z_ref + alpha_RMS*(z_Umean-z_ref)。

分母为0则置alpha_RMS=0并标记退化；记录raw、clipped、两S及实际RMS。
若raw>1而截到1，不得称严格等幅；单列“不完全匹配”并报告限制。
不能改用validation/test预测拟合，更不能使用真实病灶面积或Dice。
这个α只标定一次、冻结后评价M/H/T1；不要根据成绩改成LS或另一个比值。

保留旧D0、旧RSI和旧feature α1/3、2/3的历史参照，但环境不等价时
只作历史结果，不将它们与新组强行作精确科学优劣判断。

计时：U-RSI部署只需student一次tail，无GT/teacher输入；
完整logit插值对照通常需要teacher与student两个tail。如实计入预算。
train-side alpha标定额外前向成本单列，不隐去成“零成本”。

======================================================================
10. 指标、逐病例诊断与统计
======================================================================

所有收益相对同一个固定teacher，g_ir=Dice(pred_i,y_ir)-Dice(ref_i,y_ir)。
定义始终为图内参考平均后图间等权：
  G+ = E_i mean_r max(g_ir,0)。
  H- = E_i mean_r max(-g_ir,0)。
  H_epsilon = E_i mean_r max(-g_ir-0.005,0)。
  mean_gain = G+ - H-，必须数值核验；不能用H_epsilon替代H-。

必报：Dice、IoU、G+、H-、H_epsilon、mean_gain、soft BCE/SoftDice、
rho/J、precision/recall、预测面积、更新logit RMS、改变像素比例。
退化统计分开：
  mean_harm：图内平均g<-epsilon。
  any_harm：至少一参考g<-epsilon。
  all_harm：全部参考g<-epsilon。
  sign_conflict：min g<-epsilon且max g>epsilon。
epsilon固定0.005为主，0/0.01/0.02/0.05只作预指定敏感性；
不能拿any_harm说“这么多图整体失败”。

边界指标：原实现BF1容差max(1px,0.5%图像对角线)；0.25%/1%敏感性；
4邻域边界、欧氏双向距离拼接95百分位的HD95及对角线归一值。
空mask约定沿用原代码，不能让各组口径不同。

保留旧尾部口径：每图最小参考g，再取最差ceil(10%图数)的均值；
另报图均值尾部。M为23图，T1仅2图，避免由小尾部做普遍结论。

按选中U-Mean固定定义四类图，后验仅用于诊断：
  all-benefit：所有参考g>0.005。
  all-harm：所有参考g<-0.005。
  conflict：至少一参考>0.005且另一参考<-0.005。
  other：其余。
四类不随每个方法重新分组。比较U-RSI、RMS、四α、U-NoMessage在这些
相同图上的变化和总体贡献，检查是否再次牺牲明确有益更新。
不能将后验类别或GT传给模型推理。

M/H/T1导出逐参考CSV：包含run/checkpoint/manifest/teacher身份、
image_id/group_id/reference_id/source/tool/annotator、上述hard/soft指标，
FP/FN新增/移除计数，canonical/original loss分开，所有α值写清。
对冻结编码器、teacher和同图预测一致性逐条验收。

五组结果还必须给出因子差分：
  tail在普通目标下的变化：U-Mean - F-Mean。
  tail在RSI下的变化：U-RSI - F-RSI。
  冻结条件下RSI变化：F-RSI - F-Mean。
  解冻条件下RSI变化：U-RSI - U-Mean。
  difference-in-differences：
    (U-RSI-U-Mean) - (F-RSI-F-Mean)。
对Dice、G+、H-、H_epsilon均分列，避免把tail贡献算成RSI贡献。
若F因环境差异只能作历史参照，因子差分只能描述，不能当同条件鉴别。

比较均配对，同一次bootstrap索引用于双方，保留同图全部参考关联。
有已知病例组按组重采样，未知身份不能随意合并为同一“unknown”组；
也不能声称所有患者完全独立。沿用原已知组/图像222个单位处理，并报告。
bootstrap2000次、固定rng seed17；另报223图单位敏感性。
尾部每次重采样后重新排序。报告CI，但不把像素当独立样本。

全部CI是单seed、选中开发集的探索性证据，不是正式显著性、非劣性或
等效性证明。区间跨0不等于两法相同；多seed也不能替代独立病例。

11. 预登记的去留筛查：先冻结，再训练
======================================================================

下面数值只用于本轮资源筛查，是我们的实施选择，不是文献公认、
临床意义或投稿门槛。执行AI必须在首次全量训练前写入preregistration.json，
记录本任务书SHA与时间；不得看见新结果后改变门槛或换主要对照。
如存在工程问题，先标记INVALID，不用训练故障否证科学假设。

使用选中checkpoint的M指标。记D为Dice，H为H_epsilon，G为G+；
M=U-Mean，R=U-RSI，N=U-NoMessage，C=训练侧alpha_RMS控制。
满足下面A或B只是“值得下一次独立确认”，不是已经成功的论文方法。

路线A：实质平均收益信号。
  D_R - max(D_M,D_N,D_C) >= 0.002，即0.2个百分点。
  H_R <= H_M + 0.0005。
  需说明四个固定logit α中是否存在能解释同样收益的简单点。

路线B：保留收益前提下的风险改善。
  D_R >= max(D_M,D_N) - 0.001。
  D_R >= D_C - 0.001。
  G_M>0且G_R >= 0.8*G_M。
  H_M-H_R >= 0.001，且至少降低H_M的20%。
  H_C-H_R >= 0.0005，且至少降低H_C的10%。
若对照H为0，不能计算相对下降，路线B不通过；如G_M为0也不通过。
H_M<0.001或H_C<0.0005时，预定绝对改善没有足够headroom，记录
LOW_RISK_HEADROOM，不降低门槛，也不将它误写成算法被严格证明无效。

附加限制：
  1. 若任一固定logit α具有D>=D_R且G>=G_R且H<=H_R，并有一项
     超过预登记实用幅度（D或G差>=0.001，或H差>=0.0005），
     判为简单控制能够解释/优于，不触发继续。
  2. H或T1来源子集相对U-Mean或RMS出现Dice下降>0.005时，
     标记SOURCE_REGRESSION，不触发自动确认，不以小样本宣判普遍失效。
     同时固定报告相对U-NoMessage的来源变化；若亦下降>0.005，
     同样标记来源退化。出现退化后不重挑checkpoint/λ/α补救。
  3. raw alpha_RMS>1或S_mean为0时，主要等幅对照退化；
     单列结果，不能以“等幅通过”宣布机制成立。
  4. 同时给出配对CI和完整40轮趋势；出现末位小数优势但方向/来源
     不稳定时，判为不确定，不把阈值点估计写成正式检验通过。
  5. 为防只改善扣容差的H_epsilon，路线A/B均检查未扣容差H-和尾部：
     相对U-Mean与RMS两主要对照，H-_R不得增加超过0.0005，
     最差10%逐图最小参考gain不得下降超过0.005。
     超过时记录TOTAL_HARM_OR_TAIL_REGRESSION，不触发确认。

最终状态必须为以下之一：
  INVALID：工程/资产/预算不合规，明确修复或缺失事项。
  STOP_CURRENT_RSI：未达筛查或简单控制足以解释，不再扩λ/模块。
  INCONCLUSIVE：点估计有信号但对照退化、数值/来源/不确定性未解决。
  CANDIDATE_FOR_CONFIRMATION：满足冻结筛查且工程合规；只建议后续确认。

无论状态哪种，本轮五组完成后停止扩展、提交报告。不自动跑下一seed。
后续若确认，应固定设置重建独立seed的共同A/B，而不是只给D换随机数。
当前实验也不能单独证明异构特异性；CNN自消息及已有FD/SESV近邻是
后续有信号才考虑的归因/算法对照，不在本轮自动预算内。
