## 目标函数与日志的统一定义

每图每参考：ell=0.5BCE_valid+0.5(1−SoftDice)；分别计算完整参考，再先图内参考平均、后图间平均，记E_ir。缺失参考与padding不参与归约。

SoftDice固定为(2 sum(v*p*y)+1e-6)/(sum(v*p)+sum(v*y)+1e-6)，v为valid mask，不使用平方分母。每份样本须有有效像素。hard Dice/IoU及BF1双空记1、单空记0；HD95双空记0、单空按图像对角线惩罚。

ell0来自固定CNN anchor，d=ell_theta−ell0，epsilon_L=0。

| 目标 | 公式 |
|---|---|
| D0 | E_ir ell_theta |
| RSI | D0 + lambda E_ir relu(d) |
| Mean-Hinge | D0 + lambda E_i relu(E_r d) |
| Abs-Hard | D0 + lambda E_ir relu(ell_theta−q) |

q来自共同B检查点在M train规范无增强视图上的复合loss加权75%分位；每图权重1/N，图内每参考1/m_i。按loss升序累计权重达到0.75的最小值定义；每seed重新计算一次，D阶段固定、停止梯度，不用val/test或逐例退化标签定q。

Mean-Hinge只能先图内平均参考再hinge，不能跨batch。Fixed-Shrink不训练，从D0选定消息出发，对alpha=0、1/3、2/3、1分别真实重算tail。

记录rho=E_ir I(d>0)，J_i=E_r relu(d)−relu(E_r d)，以及同图d显著正负并存比例kappa_pm（数值容差1e-6）。记录绝对难例激活比例、权重均值、风险/分割梯度贡献，防止把优化尺度变化当新信息作用。

报告收益使用hard Dice：gD=Dice(current,reference)−Dice(anchor,reference)，阈值0.5，原图坐标。G+=E_ir relu(gD)，H_epsilon=E_ir relu(−gD−0.005)。loss收益与Dice收益不同，分别存储。

逐参考指标先图内平均再图间平均；any-harm、sign-flip和最差参考先按各自每图定义计算，不能先平均参考收益再判断有害。逐参考结果保留reference_id（mskObjectID）、seg_filename和subset，避免M/H同人不同mask互相覆盖。

## 工作点和预算规则

全部224张val作为公开开发/选择集合，不称独立确认；H/T1不单独选参。所有阶段按同一val平均hard Dice选择epoch，完全相等取更早epoch，全部跑满固定预算，保留末轮与选中checkpoint。

先lambda=1验证流水线；需要排除权重影响时，三个加权方法同补0.3和3，D0共享lambda=0。每种loss族最多4个点，Fixed-Shrink也是4点。不能只为RSI追加搜索。

每族保留val Dice不低于D0−0.002的候选，选H_epsilon最低者；并列选Dice高，再选lambda小。Fixed-Shrink并列选alpha大。选择后的val区间是探索性，不是独立显著性证据。

普通消息或首轮方法未通过时按下面的原因分流，不能打开test找权重、改骨干或删失败样本。0.002是工程非劣容差，不是临床界限。

## 时间与运行规模

不预估未经实测的GPU小时。初始seed17运行A-CNN100轮、A-T100轮、B40轮、D四种目标各40轮，共7个训练任务；另外Fixed-Shrink只做4种实际tail前向。各阶段成本不同，不能把阶段epoch相加当相同计算量。

若展开完整预登记权重网格，D阶段最多10个训练任务，总训练任务为3个共享阶段加10个D任务；seed29按下述复核规则另计。预训练下载、环境配置、文件审计和数据解码开销单独记录。

## T0：文件、划分及实现正确性

先完成完整v2第3节的文件、身份组、重复及空间对齐审计，锁定实际可用数量，禁止默认所有元数据文件都已下载。

用合成小张量和固定16张训练图（按图像ID和已知参考数量规则选择，不按模型结果选择）验收：

1. 全关消息、零消息恢复同一anchor；FP32 eval在确定性设置下allclose，atol/rtol=1e-6。记录最大绝对误差，超差先查非确定性或状态更新。
2. 一步消息更新后anchor参数、buffers及固定输入z0不变，z1可变化。
3. tail参数无梯度，输入梯度可达message；首步Wo有梯度，后续attention内部可学习。
4. 同图全部参考、valid mask同步增强，图像颜色变换不作用mask。
5. padding及缺失rater不入loss；参考排列、复制整套参考不改变归约；单参考J=0。
6. 用手算小例检查四种目标、relu先后顺序、lambda=0等于D0、q固定且无梯度。
7. 检查J恒等式数值正确，所有参考同号时J=0；这只是公式验收。
8. 原图—letterbox—逆变换坐标一致；使用nearest缩放mask可能丢失小细节，不要求任意原mask往返逐像素相同。
9. 预训练实际加载、形状和CLS正确，无Transformer绕过消息的路径。
10. 训练/选参加载器排除test，批内rater数可变，所有图标签保持同split。

这组正确性检查不计为真实机制结果。多参考互相冲突时不能要求16图训练loss必为零；只检查普通监督能学习、输出不因实现错误坍塌。

## T1：普通消息是否值得研究

seed17，使用全部验收后的M train，依次训练A-CNN100轮、A-T100轮、B40轮。val只执行实际a=0/1，保存每图每参考结果与rho/J/kappa。首次不看test。

必须回答：

- B相对anchor是否有平均正收益和可见G+？
- 是否同时存在超过epsilon_D的新增损害，其比例、幅度、尾部如何？
- 相同输出变化是否随参考改变得失，是否只来自T3或阈值末位变化？
- soft loss判断与hard Dice是否一致？

若B整体明显弱于anchor，先检查实现、Transformer监督和训练是否收敛。仅允许一次有记录的普通训练预算修订：在val曲线仍明显上升或有明确工程错误时，统一修订相关阶段并重建所有共享起点；不在失败基线上直接证明RSI“有效”。不能依据test决定是否延长。

J和翻转均几乎没有时，记录跨参考故事缺乏支持；不得因J小就宣布所有消息内容方法无效。

## T2：五组最小方法比较

通过T0，且T1有可研究的普通纠错后：

| 运行ID | 起点 | 新训练 | 参数 |
|---|---|---:|---|
| D0 | 同一B消息 | 40轮 | lambda=0 |
| RSI-1 | 同一B消息 | 40轮 | lambda=1 |
| MeanHinge-1 | 同一B消息 | 40轮 | lambda=1 |
| AbsHard-1 | 同一B消息 | 40轮 | lambda=1，q为B训练loss加权75%分位 |
| Shrink-D0 | D0选定checkpoint | 0轮 | alpha=0、1/3、2/3、1，各实际重算tail |

本短版目标函数定义为准。所有组同增强序列、有效batch、optimizer新初始化、学习率和40轮预算，按相同val Dice规则选epoch。首轮固定阈值0.5，无额外后处理、路由或六动作。

初始计算量可核算为A-CNN100+A-T100+B40+四组D各40，共400个“阶段epoch”；各阶段成本不同，不能把400当统一整网训练epoch或据此编造GPU小时。

先lambda=1是运行与机制筛查，不以它单次失败宣布方向失败。若T0/T1成立、仍需分辨权重选择影响，预登记最多补lambda=0.3和3，**RSI/Mean-Hinge/Abs-Hard同步补齐**。最多10次D训练（1个D0+3种方法各3个正权重），不能只救RSI。加上共同lambda=0点，每个loss族4工作点，对应Fixed-Shrink四个alpha。

如果普通消息无价值、工程未通过或风险项缺少训练信号，先处理对应问题，不盲目展开网格。

## 初步通过、修改与停止条件

以下是继续投入的工程筛查，不是临床或统计显著性保证。

| 观察 | 初步决策 |
|---|---|
| T0任一关键状态/梯度/标签泄漏检查失败 | 停训练，修工程并重跑受影响组 |
| B没有平均正收益且G+接近零 | 优先修基线；不把有害消息作为成功研究样本 |
| RSI相对D0平均Dice下降超过0.002 | 该工作点不合格；只在预登记有限网格内判断其他权重 |
| RSI有合格工作点，H_epsilon低于D0，正收益保留且尾部无明显反向恶化 | 有继续价值，但还要排除简单对照 |
| RSI权衡被Abs-Hard、Mean-Hinge或Fixed-Shrink支配/基本解释 | 分别收缩相对退化、逐参考或内容变化的主张，不直接加模块 |
| H下降但输出几乎等于anchor、G+接近零 | 不更新退化解，不算方法成功 |
| train rho近零而val损害明显 | 缺训练侧有效风险信号，不能靠单纯增lambda解释解决 |
| J/kappa近零，Mean-Hinge等效 | 同图参考抵消不是已被支持的主作用 |
| 只有soft loss改善，hard Dice及边界无支持 | 不宣称最终分割纠错成功 |
| 差异小、配对区间宽或方向不稳 | 结论未定，允许一个预登记seed29复核，不无限搜索 |

“支配”的操作定义：在统一指标下，一个简单对照点Dice不低、H_epsilon不高，且至少一项有实际幅度优势；结合G+和尾部检查。小幅差异与宽区间记未定，不用末位数强行判胜。lambda和alpha选择只依据本短版工作点规则，表外不新增工作点。

两个开发seed都只产生开发证据。若RSI在同等绝对性能下保留正收益并获得简单对照不能解释的损害改善，才进入T3；不要求首轮宣称新的最优成绩。

## T3与正式验证

seed29使用相同最终清单和seed17冻结的配置，各自重训A/B/D，共用自己的B起点；Abs-Hard的q按相同训练侧规则重算。先重复D0、选定RSI及seed17最有竞争力的简单对照，必要时按预定完整矩阵补齐；不重新挑lambda。

两个seed支持后，再加门控、输出修正、CNN自修正、选择性蒸馏及真实多标注近邻。此时才决定是否值得六动作。

正式配置、来源筛选、评价规则冻结后，seed101/202/303完整重训；统一释放P2 test评分。随后P1两年独立实验和PH2外测分别报告。不得在正式test看到结果后返回改损失、参考过滤或主指标。
