## 三、统一实验约定（recipe）

所有基线/对比实验严格执行同一 recipe，保证结果可直接互比：

```
数据集       ISIC2018（1886 train / 808 val），256×256
种子         42（torch/np/random，cudnn deterministic）
优化器       AdamW（betas=(0.9,0.999), eps=1e-8, weight_decay=1e-2）
调度器       CosineAnnealingLR（T_max=300, eta_min=1e-5）
epochs       300
损失         主输出 BCE+Dice（EGE 系含 5 路 deep supervision，权重 0.1~0.5）
数据增强     RandomHFlip + RandomVFlip + RandomRotation(0-360) + Resize(256)
            myNormalize（ISIC 统计 z-score + 逐图 min-max → [0,255]）
选点         best validation loss（非 best DSC，非 test）
评估         在 val 集（808 张）上评估 best checkpoint
```

**例外说明**（均已在日志中注明）：
- 显存不足时降 batch + 梯度累积（等效 batch 保持 64）：U-Net bs32×2、Swin [2,2,6,2] bs32×2
- lr 按模型类别调整（见 S2/S3 排查结论）：CNN 系 1e-3；从零 transformer 1e-4
- Swin 预训练版因加载官方权重，encoder depth 为 [2,2,6,2]（41.4M），其余从零版 lite [2,2,2,2]（27M）

## 五、机制结论汇总（全部有数据支撑）

1. **lr 是"隐藏变量"**：从零 transformer 对 lr 极其敏感。Swin：1e-3→0.8304、3e-4→0.8649、1e-4→0.8666（+3.6 质变）；PTU 同样 1e-4 最优；而 CNN 系 1e-3 最优。**混合模型跟随主干偏好**，差分 lr（CNN 1e-3 + transformer 1e-4）带来 +0.4 增益。
2. **预训练是 transformer 最大杠杆**：同结构 [2,2,6,2] 41.4M，从零 0.8613 → ImageNet 0.8939（**+3.26**）。比任何结构调整都大。
3. **容量饱和**：PTU 12.7M→63.8M（5 倍）DSC 不动（0.837 附近），Swin 加深 27M→41.4M 从零还微降。**从零小数据下容量不是瓶颈**。
4. **CNN 局部先验是"基础设施"**：纯 PTU 0.8376 + 1.34M CNN 分支 → PTU-Dual 0.8876（**+5.0**）；EGE 0.8817 + 5.29M transformer 分支 → 0.8894（+0.77）。收益不对称 = 边际递减：缺先验者获赠先验收益大，已有先验者获赠全局收益小。
5. **γ 的镜像证据**：PTU-Dual 的 γ 主动升至 0.167（模型放大 CNN 修正）；EGE-Dual 的 γ 被压在 0.05-0.1（模型抑制 transformer 修正）。网络自己"投票"：从零场景下 CNN 特征更被需要。
6. **保护式残差融合有效**：`F' = F + γ·proj(F_aux)`（γ init 0.1）在两个方向上都稳定生效，与 EGE-Wave（α≈0.13）模式一致。
7. **并行 ≥ 串行**：EGE-Dual（并行）0.8894 > EGE-Wave（串行小波）0.8863，但串行方案参数量小 100 倍。
8. **窗口注意力 > 全局注意力（从零）**：Swin 从零 0.8613 > PTU 0.8376——局部性归纳偏置在纯 transformer 内部也成立。
9. **高频子带必要**：Wave LL-only 0.8780 vs Full 0.8863（-0.83），且 BF1/HD95 同步变差；残差形式下高频在修正项中精确抵消、只改低频，是优雅的设计。
10. **融合不是创新、是基线**：保护残差 + 并行双分支为已有技术组合；其价值是统一 recipe 下的干净机制证据链，以及作为未来单变量创新的高质量基线（EGE-Dual 差分 lr 0.8894）。

## 七、关键教训与坑

1. **统一 lr 是陷阱**：不要用"项目默认 lr"直接训新架构。CNN 1e-3 / 从零 transformer 1e-4 / 差分 lr 双组。
2. **Swin 参数量差异**：[2,2,2,2] lite=27M，[2,2,6,2] 标准=41.4M；预训练版必须用后者（官方权重结构），因此"预训练 vs 从零"对比必须同用 [2,2,6,2] 才干净。
3. **ImageNet 权重适配**：window 7→8 需把每个 `relative_position_bias_table` 从 13×13 双三次插值到 15×15；decoder 按 `layers.i → layers_up.(3-i)` 反向映射加载（块数与 depth 天然对齐）；输出层/PatchExpand 无对应权重保持随机。
4. **下载大文件用代理**：`curl -x http://192.168.20.252:7897`（直连 github 会超时）。
5. **EGE 系模型输出已 sigmoid**：评估脚本别再套 sigmoid（曾导致边界指标全模型相同）。
6. **后台训练**：`setsid bash script.sh > log 2>&1 &`；链式任务曾出现静默死亡（PTU d2 卡在 epoch 7），后续统一用单任务 setsid 直启 + 独立 watcher，更稳。
7. **包名冲突**：`models` 包名在 EGE 与 PTU 项目间冲突；跨项目 import 用完整包名 `pure_transformer_unet.models.*` 或 importlib 绝对路径加载。
8. **断点续训**：只有 PTU train.py 支持（--resume）；EGE train.py 有 latest.pth 自动恢复机制但需同 work_dir。

## 八、当前基线定版与后续方向

**定版基线**（未来单变量创新的对照点）：
| 角色 | 模型 | DSC |
|---|---|---|
| 轻量 CNN 基线 | EGE baseline / EGE-Wave v1 | 0.8817 / 0.8863 |
| 纯 Transformer 基线 | PTU [2,2,4,2] | 0.8376 |
| 双分支基线（推荐） | **EGE-Dual 差分 lr** | **0.8894** |
| 上界参照 | Swin + ImageNet | 0.8939 |

**后续创新候选**（均可在 EGE-Dual 基线上做单变量叠加）：
1. 选择性高频保留（Wave 消融线的自然延伸）
2. 空间/通道自适应融合门控（替换标量 γ）
3. 弱监督主线（Weak-EGE-Wave 0.8620 的增量空间）
4. 跨数据集泛化（ISIC2017）
