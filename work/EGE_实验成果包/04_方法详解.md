## 2. 纯 CNN 基线：EGE-UNet

**结构**：6 级编码器 `[8,16,24,32,48,64]`；Stage1-3 = Conv3×3 + GroupNorm(4) + GELU + MaxPool；Stage4-6 = G-MHPA（分组多轴 Hadamard 积注意力）；5 个 GAB（分组聚合桥，多尺度扩张卷积）；5 路 deep supervision；输出 `(DS tuple, final)` 均 sigmoid。

**shape 流转**：256²×3 → t1 128²×8 → t2 64²×16 → t3 32²×24 → t4 16²×32 → t5 8²×48 → t6 8²×64 → decoder 逐级 2× 上采样 + GAB 融合 → 256²×1。

**参数量** 53,374。**结果**：DSC 0.8817。

---

## 3. EGE-Wave（串行小波注入，全系列最轻量强基线）

**思想**：在 t3（32²×24）处插入 Haar 小波适配器——低频子带（LL）过 1 层多头自注意力 + MLP 做全局建模，高频（LH/HL/HH）原样透传，IDWT 重建后以受控残差融合。

**公式**：
```
(LL, LH, HL, HH) = DWT(t3)
LL' = Pos + Transformer(LL)          # 1 block, 4 heads, mlp 2×
F_wave = IDWT(LL', LH, HL, HH)
t3_deep = t3 + α·(F_wave - t3)       # α = σ(logit)，init 0.1
```
- v1：scalar α（DSC 0.8863）；v2：逐像素 SpatialWaveGate（0.8861）
- **关键性质**：HF 在残差差项中精确抵消 → 修正只作用于低频，边界不被扰动
- 适配器参数量：5,833（+10.9%）
- 高频消融（wave_mode 参数）：`full` / `ll_only`（LH/HL/HH 置零→0.8780，证明高频必要）/ `no_ll_transformer`（IDWT∘DWT≈恒等，自检用）/ `hf_only`

## 4. Swin-Unet 的 256×256 适配与 ImageNet 预训练加载

**4.1 尺寸适配**：原生 224²/window7；256² 下 patch grid 64×64，window7 无法整除 → window_size=8。

**4.2 预训练加载（load_pretrained，三大步骤）**：
1. **结构对齐**：depth [2,2,2,2]→[2,2,6,2]（官方 Swin-T 结构，41.4M）
2. **位置偏置插值**：每个 `relative_position_bias_table` (169,h) → 13×13 网格 → 双三次插值 → 15×15 → (225,h)
3. **decoder 反向映射**：`layers.i.* → layers_up.(3-i).*`（深度与维度天然对齐）；PatchExpand/输出层无对应权重，随机初始化
- 加载量：301/354 keys
- 结果：预训练 0.8939 vs 同结构从零 0.8613 → **预训练效应 +3.26**

## 5. PTU：纯 Transformer U-Net（自建全局注意力管线）

**核心组件**：
- **PatchEmbed**：Conv2d(3→64, k4, s4) + LayerNorm → 64²×64
- **SpatialReductionAttention**：Q 全 token；K/V 经 Conv(stride=SR) 空间降采样（SR=4: 4096→256 tokens；SR=2: 1024→256）；SR=1 为全注意力。head_dim=32，pre-norm，DropPath
- **TransformerBlock**：`x + Attn(LN(x))` → `x + MLP(LN(x))`，MLP 4× GELU
- **PatchMerging**（2×2 拼接 + Linear 4C→2C）/ **PatchExpand**（Linear C→2C + 空间 2× 重排）/ **FinalPatchExpand_X4**
- **Decoder**：三阶段 [2,2,2]，Concat+Linear skip，SR=[1,2,4]

**规格**（Exp0）：embed_dims=[64,128,256,512]，depths=[2,2,4,2]，heads=[2,4,8,16]，SR=[4,2,1,1]，14.19M。

**实验矩阵**：Depth 2/4/6 与容量 14→64M 均无收益（0.837 平台）。

## 6. EGE-Dual：CNN 主干 + Transformer 并行分支（核心方法）

**6.1 总架构**：
```
Input ──┬── CNN 主路（EGE encoder 原样，受保护）
        │      enc1-3 → t2 ──[+γ₂·proj(T1)]──→ enc4 → t3 ──[+γ₃·proj(T2)]──→ enc5
        │      → t4 ──[+γ₄·proj(T3)]──→ enc6 前 t5 ──[+γ₅·proj(T4)]──→ t6
        │      （被修正的 t2-t5 同时进 GAB skip）
        └── Transformer 并行分支（轻量 PTU encoder，从原始图像输入）
               PatchEmbed4 → 64²×48(SR4) → 32²×96(SR2) → 16²×192(全) → 8²×384(全)
```
分支规格：t_embed=48，[2,2,2,2]，head_dim=16（heads=[3,6,12,24]），SR=[4,2,1,1]，drop_path 0.1，5.29M。

**6.2 保护式残差融合（FusionInject）**：
```
F'_CNN = F_CNN + σ(γ)·Conv1×1(F_T)      # 每尺度独立 γ，init 0.1
```
- 注入点：t2(64²×16←48)、t3(32²×24←96)、t4(16²×32←192)、t5(8²×48←384)
- decoder/GAB/5 路 DS 完全不动；输出格式与 EGE 相同（engine 零改动）
- 总参数量 5.34M；γ 训练后停留在 0.05-0.1（模型主动压低修正量）

**6.3 两种训练模式**：
- 统一 lr=1e-3：0.8854
- 差分 lr（§8）：**0.8894**

## 7. PTU-Dual：Transformer 主干 + CNN 并行分支（镜像）

- 主干：PTU [2,2,4,2]/embed64 encoder+decoder 原样
- 分支：纯卷积分支（stem Conv s2 + MaxPool + 3×ConvStage(GN+GELU+MaxPool)，通道 [32,64,128,256] @ 64/32/16/8），**不含任何注意力**（1.34M）
- 融合：同 FusionInject（tokens 主路 + spatial 分支 → 1×1 投影 → `F' = F + σ(γ)·proj(F_aux)`）
- 差分 lr 反向：主干 @1e-4，CNN 分支 @1e-3
- 结果：0.8876；γ 升至 0.167（与 EGE-Dual 镜像）

## 8. 差分学习率（differential lr）

**动机**：从零 transformer 最优 lr=1e-4，CNN 最优 lr=1e-3；混合模型统一 lr 会让其中一支处于次优。

**实现**（AdamW 双参数组，CosineAnnealingLR 对两组各自从初值退火）：
```python
optimizer = torch.optim.AdamW([
    {'params': cnn_params, 'lr': 1e-3},
    {'params': branch_params, 'lr': 1e-4},
], weight_decay=1e-2)
```
- EGE-Dual：CNN+fusion 81K @1e-3 / T 分支 5.26M @1e-4 → +0.4（0.8854→0.8894）
- PTU-Dual：反向分组 → 成立
- 通用结论：**混合模型按支路类型分组设 lr**

## 9. 尺度条件化融合（SCF，E-B 创新点候选）

**动机**：误差结构分析发现小病灶 DSC 0.815（vs 大病灶 0.885）；标量 γ 无法区分病灶尺度。

**方法**：γ 从"每尺度一个全局标量"改为"每样本门控"：
```
desc = GAP(F_CNN.detach())             # B×c_dim，detach 防门控操纵特征（loss 解耦）
γ = σ(Linear(GELU(Linear(desc))))      # 2 层 MLP，B×1
F' = F_CNN + γ·Conv1×1(F_T)
```
**两个关键设计**：
1. 描述子 `detach()`——避免门控通过扭曲 CNN 特征自证有用（沿用项目"loss 要解耦"铁律）
2. 零初始化——gate 末层 weight=0、bias=logit(0.1)，**训练起点与 scalar 版完全一致**（单变量干净）；需注意在 `self.apply(_init_weights)` 之后重设

**结果**：DSC 0.8895（打平）；Sens +1.69（0.8947）；**γ-病灶面积 Spearman r=-0.636（p≈1e-93）**——门控学到"小病灶获得更多 transformer 全局修正"（小病灶局部信息不足，需要全局上下文定位）。

## 10. 小病灶尺度增强（E-A，诊断驱动）

**动机**：小病灶短板。**实现** `myRandomScaleCrop`：
```
s ~ U(0.5, 2.0)；图像双线性 resize 到 s×256，mask 最近邻 resize
→ 不足 256 时图像 reflect / mask 零填充 → 随机裁剪 256×256
```
- 以 p=0.5 应用，保持一半批次原始分布
- 结果：DSC 0.8860（负向），Sens +1.95——证明平衡可调但数据扰动治标不治本

## 12. 评估方法

**12.1 主指标**：混淆矩阵级 DSC/mIoU/Sens/Spec（阈值 0.5，与项目历史一致）。

**12.2 边界指标**（tests/eval_boundary_metrics.py）：
- BF1：预测/GT 边界（膨胀半径 2 的 XOR 环）的 F1
- HD95：双向距离变换的 95 分位 Hausdorff
- ASSD：双向平均对称表面距离

**12.3 效率**（tests/eval_efficiency.py）：thop 计 FLOPs + 实测 step 时间/峰值显存（AdamW 训练态）。

**12.4 lr 过拟合代理**：100 图/40ep/带增强，报 train DSC，用于全量前预筛 lr。
