## S1 基线对比：U-Net 与 Swin-Unet 接入（2026-08-22）

### 1.1 目标
在统一 recipe 下建立两个外部基线：原版 U-Net（milesial/Pytorch-UNet）与 Swin-Unet（官方实现），与 EGE 系列对比。

### 1.2 U-Net 接入
- 代码：`Pytorch-UNet-master/train_unet_isic.py`（自建脚本，非原仓库 train.py）
- 关键适配点：
  1. 数据管线复用 EGE 的 `NPY_datasets`（用 importlib 按绝对路径加载，规避包名冲突）
  2. 模型输出是 logits，loss 前需 `torch.sigmoid()`
  3. 原仓库默认 RMSprop/lr=1e-5/batch=1 全部替换为统一 recipe（AdamW 1e-3）
  4. 显存：31M 参数 @256×256，bs=32 OOM → **bs=32 × 梯度累积 2（等效 64）**
- 结果：DSC 0.8697（best epoch 138）

### 1.3 Swin-Unet 接入
- 代码：`Swin-Unet-main/train_swin_isic.py`
- 关键适配点：
  1. **尺寸适配**：原生 224×224/window7 → 256×256 必须 window_size=8（256/4=64，64%8=0；window7 无法整除会报错）
  2. 输出 logits → sigmoid → BceDiceLoss
  3. 用 lite 配置（encoder depths [2,2,2,2]，27M）
- 结果：DSC 0.8304 —— **明显异常**（预期 0.85+），触发 S2 排查。

## S2 Swin 落后的排查：实现 bug 还是 lr？（2026-08-22~23）

### 2.1 排查手段一：训练曲线检查
曲线健康收敛（ep30 0.789 → ep120 0.821 平台），无发散 → 不是训练事故。

### 2.2 排查手段二：独立重载评估
best checkpoint 复算结果与训练日志一致（0.8304 可复现），逐图 DSC median=0.889、预测连贯无全 0/全 1 → 不是评估 bug。

### 2.3 排查手段三：100 图过拟合测试（决定性证据）
方法：取 100 张训练图，无增强、drop_path=0，40 epochs，看 train DSC：
- lr=1e-3 恒定：**卡死在 DSC 0.73**（27M 模型过拟合不了 100 张图 = 优化失败）
- lr=3e-4 恒定：DSC 0.86 正常学习
- lr=1e-2 / SGD 0.05：直接崩溃（DSC 0.0）

结论：**代码无 bug，lr=1e-3 对从零 transformer 过高**，模型陷入次优 basin。EGE 小模型（59K）能吃 1e-3，27M transformer 不能。

### 2.4 lr 扫描定版
- 过拟合代理筛 7 个 lr（5e-5~1e-3），单调趋势"越低越好"
- 全量验证：3e-4 → 0.8649；1e-4 → 0.8666（+3.6 相对 1e-3）
- 该"100 图过拟合代理筛选法"后被固化进 `scripts/` 作为通用工具，在 PTU/EGE-Dual 上复用且与全量结论一致

## S3 预训练实验（2026-08-25）

### 3.1 下载官方权重
- 直连 GitHub 超时；发现环境代理 `WAAS_HTTP_PROXY=http://192.168.20.252:7897`，用 `curl -x` 下载成功（114MB）

### 3.2 三大适配（全在 `train_swin_isic.py` 的 `load_pretrained()`）
1. **结构对齐**：官方 Swin-T 是 [2,2,6,2]，lite 是 [2,2,2,2] → 模型 depth 改为 [2,2,6,2]（41.4M）。**这埋下了后来的对比混淆**（见 S3.4）
2. **位置偏置插值**：window 7→8 使每个 `relative_position_bias_table` 从 (169,h) 变 (225,h)，用 `F.interpolate` 双三次将 13×13 插到 15×15
3. **decoder 反向映射**：`layers.i → layers_up.(3-i)`，块数与维度天然对齐（这是原论文"encoder+decoder 都用预训练权重"的做法）

### 3.3 结果
- 预训练版：**0.8939**（best epoch 13，明显过拟合：峰值 0.8983@ep30 后缓降）
- 加载验证：301/354 keys（其余为 PatchExpand/输出层，无 ImageNet 对应）

### 3.4 消歧：同结构从零对照
用户发现"预训练版 41.4M vs 从零版 27M"参数量不同 → 补跑 **Swin [2,2,6,2] 从零**（41.4M，lr=1e-4）：0.8613。
→ 干净结论：**预训练效应 = 0.8939 - 0.8613 = +3.26**（同结构唯一变量）。

## S4 纯 Transformer U-Net（PTU）自建（2026-08-26）

### 4.1 设计（依 task/Pure_Transformer_UNet_Baseline 方案）
- Efficient Global Attention：Stage1/2 SR=4/2 压缩 K/V，Stage3/4 全注意力
- 规格：embed 64、[2,2,4,2]、heads [2,4,8,16]、head_dim 32、decoder [2,2,2]、Concat+Linear skip
- 验收：stage token (4096/1024/256/64) 全对、输出 (B,1,256,256)、无 NaN、14.2M 参数

### 4.2 实验
- Exp0（lr=1e-4，经代理筛选）：**0.8376**（best ep 102）
- Depth Scaling：d2 0.8374 / d4 0.8376 / d6 0.8327 → Stage3 深度无收益
- 容量 Scaling（PTU-SYM12，63.8M，Enc+Dec 16×16 双 12 层）：0.8341 → **容量饱和**

### 4.3 事故与恢复
- PTU d2 训练静默死亡（epoch 7 后卡死无日志）→ 教训：链式任务不可靠，改用单任务 setsid + 独立 watcher
- 为 PTU 实现**断点续训**（--resume/--work_dir，恢复 model/optimizer 双参数组/scheduler/min_loss）

## S5 双分支：EGE-Dual（2026-08-29）

### 5.1 设计与实现（models/ege_dual.py）
- CNN 主路 = EGE encoder 原样；Transformer 分支 = 轻量 PTU encoder（embed48/[2,2,2,2]，5.29M）
- 保护式残差融合 4 尺度（t2-t5）：`F' = F_CNN + σ(γ)·Conv1×1(F_T)`，γ init 0.1
- decoder/GAB/5 路 DS 不动；输出 tuple 格式不变（engine.py 零改动）

### 5.2 两轮优化
1. 统一 lr=1e-3（代理筛选：1e-3 最优，混合模型跟随 CNN 主干偏好）：**0.8854**
2. **差分 lr**（CNN+fusion 81K @1e-3，分支 5.26M @1e-4，双参数组 AdamW）：**0.8894（+0.4）**

### 5.3 镜像：PTU-Dual（models/ptu_dual.py）
- T 主干 + 纯卷积分支（1.34M，无注意力污染）+ 同保护式融合
- 差分 lr 反向（T @1e-4，CNN @1e-3）：**0.8876**（较纯 PTU +5.0）
- 机制：γ 主动升至 0.167（模型放大 CNN 修正）——与 EGE-Dual 的 γ 被压形成**镜像证据**

## S6 指标优化轮（2026-08-30）

### 6.1 误差结构诊断
- 逐图 DSC：62% 图 >0.9；最差 2.7%（22 张）<0.5
- 小病灶（<1k px）DSC 0.815 vs 大病灶 0.885 → 明确短板
- 推理侧阈值扫描 + TTA（3 翻转）+ 孔洞填充：基线 0.8894 → **0.8931**

### 6.2 E-A 小病灶尺度增强（负向）
- 实现 `myRandomScaleCrop`（0.5-2.0 缩放 + 随机裁剪，mask 最近邻插值，reflect/0 填充）
- 结果：DSC 0.8860（-0.34），Sens +1.95（0.8778→0.8973），全阈值峰值 0.8871
- 结论：小病灶短板不是尺度分布问题；但**证明 Sens/Spec 平衡可调 ±2 点**

### 6.3 E-B 尺度条件化融合 SCF（机制成功）
- 实现：γ 从全局标量 → per-sample 门控（CNN 特征 GAP 描述子 → 2 层 MLP → σ）
- 两个关键设计：① descriptor `detach()`（loss 解耦，防门控操纵特征）；② gate 零权重 + bias=logit(0.1)（**起点与 scalar 版完全一致**）
- **bug 记录**：`self.apply(_init_weights)` 会重置 gate 初始化（γ 变 0.5），必须在 apply 之后重新初始化
- 结果：DSC 0.8895（打平），Sens +1.69
- **机制验证**：γ-病灶面积 Spearman r=-0.636（p≈1e-93）——门控学到"小病灶获得更多 transformer 修正"
