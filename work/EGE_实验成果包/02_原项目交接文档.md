# EGE-UNet 系列改版项目交接文档

> 生成日期：2026-08-15
> 项目根目录：`/root/EGE-UNet-main/`
> 方案文档：`/root/*.md` 与 `/root/task/*.md`
> 全部实验基于 ISIC 2018（1886 train / 808 val），256×256，seed=42，AdamW(lr=1e-3, wd=1e-2)，CosineAnnealing，300 epochs，batch=64。

---

## 一、项目概览

本项目在原始 **EGE-UNet**（轻量级皮肤病灶分割网络）基础上，围绕两条主线做了多轮改版实验：

1. **全监督主线**：在 Stage3 插入各类 Transformer/Wavelet 适配模块，比较谁能在不破坏 EGE 轻量特性的前提下提升精度。
2. **弱监督主线**：训练时完全不使用完整 lesion mask，仅用 Bounding Box + ISIC 2018 Task2 语义属性点，探索"监督粒度-表征粒度对齐"是否有效。

**最终结论一句话**：全监督最优是 EGE-Wave v1（DSC 0.8863）；弱监督最优是 Weak-EGE-Wave Baseline（DSC 0.8620，达全监督上限的 97.3%）；其余"保护式残差修正"类模块（PRH/PSUDR）均为中性或负面。

## 三、原始数据与预处理

### 3.1 数据来源

| 数据 | 位置 | 说明 |
|---|---|---|
| 全监督图像+mask | `data/isic2018/` (1886 train + 808 val) | 256×256 PNG，数字命名 0.png~1885.png |
| 官方 ISIC 2018 原始包 | `/root/isic2018_official/` | Task1 图像/GT + Task2 五类 attribute masks，`ISIC_<id>` 命名 |
| 弱标签 JSON | `data/isic2018/weak_annotations/weak_train.json` | box + 语义点，离线预生成 |

### 3.2 弱监督数据生成流程

1. 官方 Task1 GT 按 ID 排序，映射到现有数字索引（`index i → sorted_ids[i]`，已验证 0→ISIC_0000000）。
2. `scripts/audit_weak_annotations.py` 审计：Task2 匹配率 100%，87.6% 图像有至少一个非空 attribute → GO。
3. `scripts/build_weak_annotations.py`：
   - **Box**：从 Task1 GT 提取 tight box（训练时不可见，只用于离线生成）。
   - **Semantic Points**：每个非空 attribute mask 取最大连通域中心点（radius=2 光栅化），最多 5 points/图。
   - 结果：1886 张中有 **1474 张**至少含 1 个点（eligible train set）。
4. 训练 Dataset 只读 image + weak_train.json，**禁止读完整 lesion mask**。

### 3.3 弱监督三区域定义

```
Positive = 语义点小圆盘
Negative = Box 外区域
Unknown  = Box 内 - 语义点（训练时 ignore）
```

## 四、代码文件详细说明

### 4.1 `models/egeunet.py`（核心，7 个模型类）

| 类名 | 位置 | 说明 |
|---|---|---|
| `EGEUNet` | 基类 | 6 级编码器[8,16,24,32,48,64]，Stage4-6 用 G-MHPA 注意力，5 个 GAB 桥，5 路 deep supervision。输出 `(deep_sup_tuple, final_prob)`。 |
| `BGCTEGEUNet` | EGEUNet 子类 | GAB3 换为 `BoundaryGuidedCrossTransformerBridge`（窗口交叉注意力）+ `BoundaryHead`，输出 dict（含 edge_logits）。 |
| `EGEHRViTUNet` | EGEUNet 子类 | t3 插入 `EGEHRViTAdapter`（12 层 Transformer + halting schedule），含 `no_halting` 开关。 |
| `EGEWaveUNet` | EGEUNet 子类 | t3 插入 `WaveletGlobalAdapter`（DWT→LL Transformer→IDWT→融合）。**v1 为全系列最优**。 |
| `EGEWavePSUDRUNet` | EGEWaveUNet 子类 | 在 GAB2/GAB1 后加 `PSUDR` 解码细化模块，输出 dict（含 psudr_stats）。 |
| `EGEPRHUNet` | EGEUNet 子类 | t3 插入 `ProtectedResidualHaltingAdapter`，protected t3_skip 进 GAB，输出 dict（含 edge_logits）。 |
| `EGEWaveWeakUNet` | 弱监督版（在 ege_wave_weak.py） | 含 `ll_aux_head`（LL Transformer 输出）和 `local_aux_head`（t3_skip），`forward(x, return_aux=True)` 返回 dict。 |

**全监督 forward 通用模式**（以 Wave 为例）：
```python
t3 = stage3(...)
t3_skip = t3                     # protected skip → GAB/decoder
t3_deep = wave_adapter(t3)       # 处理 → Stage4
...decoder 各阶段 GAB + deep supervision...
```

### 4.2 `models/wavelet_adapter.py`（EGE-Wave 核心）

- `HaarDWT2D` / `HaarIDWT2D`：Haar 小波分解/重建（LL/LH/HL/HH 四个子带）。
- `LFTransformerBlock`：仅对 LL 子带做 1 层多head自注意力 + MLP。
- `SpatialWaveGate`：v2 的逐像素门控融合。
- `WaveletGlobalAdapter`：主模块。
  - **v1 用 `fusion_type='scalar'`**：`output = t3 + α·(x_rec - t3)`，α=sigmoid(alpha_logit)，α_init=0.1。
  - **v2 用 `fusion_type='spatial_gate'`**：逐像素门 `out = x + gate·(x_wave - x)`。
  - 二者效果几乎相同（0.8863 vs 0.8861），v1 更简洁。

### 4.3 `models/dynamic_adapter/ege_hrvit_adapter.py`

12 层结构：Block1-3 = 窗口注意力（全 token）→ `EdgeRouter` → Block4-12 = 全局自注意力（仅 active token）+ 2 个 `ContextRefresh` 交叉注意力 → `reconstruct_tokens`（memory 回填）。

**新增 `no_halting=True` 模式**：复用原 `keep_all` 全 token 分支，绕过 Router/Selection/Reconstruction，附带 token-count assert、router/reconstruct 调用计数器、调试日志。用于 NoHalting 消融实验。

### 4.4 `models/prh_adapter.py`（ProtectedResidualHaltingAdapter）

```python
S = Blocks1-3(x)                          # Dense Base，永久保留
p = sigmoid(Router(S.detach()))           # Router 与主干解耦
A = TopK(p, ρ·N)                          # ρ: 20ep=1.0 → 40ep=0.5 → 0.5
D_A = Blocks4-12(S_A; S)                  # active 深算，memory=完整 base
Δ_A = D_A - S_A                           # 残差修正
C_A = p_A ⊙ Δ_A                           # 置信度门控
F = S + γ·Scatter(C_A)                    # γ=σ(logit)，init 0.1
```
- Edge loss：`L_edge = BCEWithLogits(edge_logits, edge_gt, pos_weight=14.48)`，edge_gt 由 mask 32×32 自适应池化得到（0<ratio<1 为 edge token）。
- 总 loss：`L = L_EGE(seg + deep_sup) + L_edge`。
- 删除原 reconstruction 相关全部组件。

### 4.5 `models/psudr.py`（ProtectedScaleUncertaintyRefinement）

在 GAB2/GAB1 后：
```python
p = sigmoid(mask_logits.detach())                 # detach 避免耦合
U = 4p(1-p)                                       # 不确定性图 [0,1]
a = mean(p)                                       # 病灶尺度描述符
w = softmax(MLP(a))                               # 尺度自适应权重
R = w1·D1(E) + w2·D2(E) + w3·D3(E)                # 三分支 DWConv dilation=1/2/3
F_new = F_gab + β·(U ⊙ R)                         # β=σ(logit)，init 0.05
```
- 只在 GAB2（用 t2）和 GAB1（用 t1）两级插入，各独立 β。
- 不新增任何额外 loss，完全沿用 Wave v1 的 `GT_BceDiceLoss`。

### 4.6 弱监督模块

- `datasets/isic2018_weak.py`：`ISIC2018WeakDataset`，返回 image/box/pos_mask/neg_mask/unknown_mask（full 模式另含 image_weak/image_strong 双视图）。
- `losses/weak_losses.py`：`balanced_partial_bce`（正负分别归一化）、`projection_loss`（box→LL 纵横投影）、`local_positive_loss`、`unknown_consistency_loss`（weak/strong 双视图，stop-grad）。
- `train_weak.py`：baseline 与 full 两种训练循环。

## 五、方法详解与设计动机

### 5.1 全监督主线演进

| 阶段 | 动机 | 结果 | 教训 |
|---|---|---|---|
| EGE-UNet baseline | 起点 | 0.8817 | 参照点 |
| BGCT（边界引导跨Transformer桥） | 加强边界信息 | 0.8825 | 边界监督让模型过保守（Sens↓） |
| EGE-HRViT（动态 halting） | 动态计算节省 | **0.8550（最差）** | Halting/Reconstruction 破坏特征连续性 |
| EGE-Wave v1（小波+LL Transformer） | 低频全局建模，残差保护 | **0.8863（最优）** | 简单残差融合最稳 |
| EGE-HRViT-NoHalting | 验证 halting 是否元凶 | 0.8857 | **确认 halting 是元凶**，12L Transformer 本身没问题 |
| EGE-PRH | 保留动态计算但修复退化 | 0.8817 | 50% token 保住 99.5% 精度，但无净增益 |
| EGE-Wave-PSUDR | 加强 Decoder 高分辨率恢复 | 0.8815 | scale router 塌缩 + β 失控，无收益 |

### 5.2 核心设计原则（反复验证得出的经验）

1. **原始特征保护**：不要用复杂分支直接替换原始特征，用 `原始 + γ·修正` 的受控残差形式（Wave v1 成功、PRH/PSUDR 中性均印证）。
2. **背景判别优先**：所有"更强语义筛选"类模块（边界、halting、scale）都易导致 Sens↓/Spec↑ 的保守收缩。
3. **loss 要解耦**：Router 输入需 `detach()`，避免辅助 loss 污染主干表征。

### 5.3 弱监督主线

- **Weak-EGE-Wave Baseline**：同 Wave v1 结构，只用 Box + 语义点 + partial BCE，**DSC 0.8620**（达全监督上限 97.3%）。
- **FG-HWS Full**：加 LL box 投影 loss + local point loss + unknown consistency，DSC 0.8571（更差，over-segmentation）。
- **诊断实验**（B1/B2/B3 隔离测试）：三个组件单独添加全部无正贡献 → 按计划停止 FG-HWS，Weak Baseline 作为弱监督主基线。

### 6.3 关键诊断数据

- **Gap Recovery**：Weak Baseline 距全监督上限 0.8863-0.8620=0.0243，弱监督已恢复 97.3%。
- **NoHalting 验证**：取消 halting 后 Spec 从 0.9353→0.9689（+0.034），证明 HRViT 退化 100% 来自 halting/reconstruction。
- **PSUDR 诊断**：beta_gab2 涨到 0.38（init 0.05）、scale softmax 塌缩（GAB2→只用 d=3，GAB1→只用 d=2）→ 修正过强，Sens 下降。
- **效率对比**：PRH rho=0.5 时 batch64 单步 0.26s vs NoHalting 1.16s（4.5× 快），显存 6.9GB vs 14.7GB。

## 八、复现注意事项（坑）

1. **checkpoint 选择标准**：全部沿用"best val loss"，不是 best val DSC（文档 37 节要求，脚本 `loss < min_loss` 时保存）。
2. **后台训练**：用 `setsid bash script.sh > log 2>&1 &` 启动可脱离 SSH 会话，日志用 `tee` 保留。不要用裸 `nohup` 于 shell 工具中（会被 timeout 杀死）。
3. **Batch=64 显存**：Wave 系列 OK；NoHalting 峰值 14.7GB（A10G 22GB 可跑）；PRH 6.9GB；PSUDR 4GB。若 OOM，优先减 batch+梯度累积，勿动 Transformer 层数/token 数。
4. **任务文档均强调**：不得用 test set 选 checkpoint、不得同时加多个新模块、改动前先读源码确认真实 shape（t1=[B,8,128,128] etc.）。
5. **模型输出格式**：不同分支返回格式不同（tuple / dict），engine.py 已按 `network` 名分发；新增模型必须同步改 engine.py 的 is_xxx 分支。
6. **类定义顺序**：egeunet.py 中子类必须定义在父类之后（曾因 EGEWavePSUDRUNet 放在 EGEWaveUNet 前报 NameError）。

## 十、最终结论与后续建议

### 核心结论

1. **全监督最佳路线 = EGE-Wave v1**（DSC 0.8863）：低频全局建模 + 标量残差保护，简单有效。
2. **弱监督可行 = Weak-EGE-Wave Baseline**（DSC 0.8620）：仅用 Box + 语义点即可达上限 97.3%。
3. **Halting 是 HRViT 失败元凶**（NoHalting 从 0.8550→0.8857 证明）。
4. **"保护式残差修正"方向（PRH/PSUDR）稳定但不增益**：证明在 Wave v1 已达的精度水平上，此类受控修正难再突破。
5. **通用失败模式**：任何让模型更"保守"的机制（边界监督/halting/scale 选择/refinement）都会 Sens↓ Spec↑。

### 后续方向建议（按优先级）

1. **弱监督进阶**：Weak Baseline（0.8620）是目前最值得投入的增量空间，可尝试语义点扩展（每 attribute 多点）、或对 B2 consistency 加 confidence masking / ramp-up（诊断显示它最接近持平）。
2. **Wave v1 改进**：既然 12L Transformer 没问题（NoHalting 0.8857 ≈ Wave v1），可探索 LL Transformer 加深/多尺度 DWT 分解与 Wave v1 融合。
3. **效率**：PRH 的 50% token 稀疏化（0.8817，4.5× 提速）可作为部署版，若接受 0.005 DSC 损失。
4. **数据/域扩展**：当前仅 ISIC2018，可扩展到 ISIC2017/2019 验证 Wave v1 泛化性。
