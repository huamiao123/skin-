## 1. 本版研究决定与互补关系

**先在固定且可靠的CNN分割基准上，学习在多个真实参考下较少造成退化的消息。旧六动作控制保留为后置诊断和强对照。**

研究问题：同一次跨分支更新，在多份真实参考标注下是否存在有实际幅度的得失冲突；逐参考约束相对退化，能否比普通平均监督、普通难例加权和缩小更新取得更好的纠错—损害权衡？

部署仍为RGB输入、一张概率图和一张二值mask输出；不输入参考标注、医生身份、GT分歧或真实动作收益。

| 修订点 | v2决定 | 目的 |
|---|---|---|
| 内容学习与动作选择 | 先学习消息内容，六动作后置 | 第一轮明确方法作用来自哪个改变 |
| 关闭状态的含义 | 先训练完整CNN，再冻结为anchor | 关闭消息恢复真实训练过的映射 |
| 强对照优先级 | Abs-Hard提前到首轮，给出明确公式 | 排除普通困难样本加权 |
| 训练与评价 | loss收益、hard Dice收益分别存储 | 防止将校准改善当作mask改善 |
| 是否利用参考冲突 | 新增rho、J、kappa及梯度日志 | 直接检查拟议作用路径 |
| 数据 | IMA-only为核心；ISIC独立协议补充 | 真实多参考机制需要多参考数据 |
| 局部干预 | 未经支持训练的六动作不作主要证据 | 防止未训练状态制造损害 |
| 原工程交付陈述 | ZIP与12项测试未在本地复核 | 不将待实现接口说成现成训练项目 |

当前按**一个方法候选及其机制证据**推进。残差、cross-attention、冻结网络和hinge各自不是发明；诊断公式不算第二算法创新。将来选择器若提供独立增量，再讨论第二方法贡献。

## 2. 假设、故事与可被推翻的主张

| 假设 | 需要的证据 | 不支持时的处理 |
|---|---|---|
| 普通消息总体有用但会造成部分损害 | 同checkpoint实际on/off，在开发数据上同时存在平均收益与明显退化 | 先排查训练/实现；不把失败消息当研究成功 |
| 同次更新的评价依赖真实参考 | 相同输出对不同参考出现有幅度的得失变化；按来源分层 | 只能研究一般相对基准退化，弱化跨参考故事 |
| 逐参考相对退化有方法价值 | 同架构、标签、预算下优于D0、Abs-Hard、Mean-Hinge与固定缩放 | 不将普通加权或更多训练包装为新机制 |
| 内部消息位置和Transformer内容有必要 | 后续同目标输出修正、CNN自修正不能解释收益 | 收缩为一般分割修正，不坚持异构交互必要 |
| 结论可复现 | 固定配置后的多个完整训练seed及独立载体支持 | 只报告已验证范围，不推广所有混合网络 |

叙事顺序：

1. 一次实际更新的平均收益，不能完整描述其新增错误。
2. 真实参考可能不一致，同一更新的得失也可能不同；这需要实验，不预设原因是医生风格。
3. 多参考均值监督可能使部分改善抵消部分退化；是否实际发生，用第6节诊断。
4. 固定基准后，对每份完整参考分别惩罚相对退化，学习消息内容。
5. 用强对照判断收益是否超出难例加权、普通保守更新和输出修正。

不宣称CNN天然负责边界、Transformer天然负责全局；不从冻结表示实验推断“私有特征被破坏”。多来源参考稳定不等于临床安全或真实边界恢复。

## 4. 共用基线和最小网络

### 4.1 受控载体

采用普通自建载体CIR-Base，不冒充原版TransFuse，也不将其残差结构作为创新。所有目标组使用同一实例配置。

| 张量 | 256输入下形状（不含batch） | 来源 |
|---|---|---|
| C4 | 64×64×64 | ResNet34 layer1 |
| C8 | 128×32×32 | layer2 |
| C16 | 256×16×16 | layer3；不使用layer4 |
| T16 | 384×16×16 | 非distilled DeiT-Small patch16，去CLS |
| F16 | 128×16×16 | C16普通投影/卷积 |
| F8 | 128×32×32 | F16上采样，与投影C8拼接后卷积 |
| M | 128×32×32 | F8为query、T16为context的cross-attention |
| z | 1×256×256 | tail结合C4后输出 |

公式：

\[
M_\theta=W_o\operatorname{MHA}(P_qF_8,P_kT_{16},P_vT_{16}),\quad
z(a)=D_{\rm tail}(F_8+aM_\theta,C_4).
\]

内部维度128、4头；输出投影Wo的权重和bias均零初始化，只零最后这一层，其他attention层正常初始化。第一步内部梯度可能为零，Wo先更新；随后检查内部梯度。明确MHA内置Q/K/V投影与外置投影如何组合，打印实际参数量。

新decoder使用GroupNorm、同一种激活；特征和logit双线性插值统一align_corners=False。位置编码插值、预训练加载与缺失key必须实际验收。

没有Transformer绕过消息入口进入tail的skip或预测旁路。a=0应严格恢复同一CNN基准。完全padding的context token在消息attention中屏蔽，但这不等于消除Transformer编码阶段padding传播。

### 4.2 与旧载体和公开方法的关系

旧方案ResNet18/DeiT-Tiny、352输入、stride16入口，与本版ResNet34/DeiT-Small、256输入、stride8入口不同。不能分别训练后将结果差异归于新目标。

TransFuse-S用于独立公开性能参照和后续载体复核。其原BiFusion不等于简单C+M，官方源码有固定12×16 token reshape。原协议复现和统一协议适配分列，不能默改mask插值或输入形状仍称忠实复现。

首轮不以复现十个模型为前置条件。机制支持后再补至少一种真实多标注方法、独立强性能基线、输出修正及CNN自修正。

## 5. 分阶段训练与工程不变量

| 阶段 | 可训练部分 | 首版预算 | checkpoint规则 |
|---|---|---:|---|
| A-CNN | CNN+完整普通decoder | 100 epochs | val平均hard Dice最大 |
| A-T | Transformer+普通辅助分割头 | 100 epochs | 同上 |
| B | 普通消息 | 40 epochs | 同上 |
| D0/RSI/Mean-Hinge/Abs-Hard | 同一结构消息 | 各40 epochs | 同上，完全相等取更早epoch |

各组都跑完预定预算；保存末轮和选定checkpoint。首轮仅图像侧开发验证，不据test选任何epoch。所有D组共享同一个B起点、训练参考、增强序列及优化器新初始化规则，不让RSI继承额外优化器步数。

A阶段两条分割路径使用完全相同M训练图与参考协议。先逐参考计算损失，再每图平均。Transformer辅助头保证context已受分割监督，部署主路径不需要该辅助头。

B阶段冻结CNN、Transformer、prefix、tail的全部参数及buffers，只优化消息；先确认普通消息有平均纠错收益。D阶段复制同一B消息，改变目标。D0继续训练不可省略。

冻结路径正确写法：

```python
with torch.no_grad():
    f8, c4 = frozen_cnn_prefix(images)
    t16 = frozen_transformer(images)
    z0 = frozen_tail(f8, c4)
m = message(f8, t16)
z1 = frozen_tail(f8 + m, c4)  # 必须保留tail对m的输入梯度
loss = objective(z1, z0.detach(), masks, present, valid)
loss.backward()
```

冻结模块同时requires_grad=False、eval；不要整体model.train后忘记恢复其状态。每轮核参数/buffer hash和固定输入z0。对同一增强图像计算anchor；不同增强不可复用原图特征或原图anchor损失。eval不等于no_grad，避免不兼容的inference_mode张量进入可微路径。

Wo=0的首步不要求全部内部参数非零梯度；不能因此错误判定实现失败。部署只解码最终z1，训练/诊断的z0及动作枚举成本另记。

端到端微调后置；若开展，保留独立冻结teacher作固定参照。当前内部off与固定teacher是不同估计对象，不能只detach一个持续变化的共享网络输出。

## 6. 损失、收益与新增诊断

### 6.1 基本损失和收益

\[
\ell_{ir}(z)=0.5\,{\rm BCE}_{valid}(z,y_{ir})
+0.5[1-{\rm SoftDice}(\sigma(z),y_{ir})].
\]

BCE在有效像素取均值；SoftDice每份完整参考单独计算。batch内缺失参考和padding不参与归约。记E_ir为先每图参考等权，再图像等权；不是所有mask直接等权。

固定SoftDice口径，v为有效像素mask，p为sigmoid概率：

\[
{\rm SoftDice}(p,y)=
\frac{2\sum_x v_xp_xy_x+10^{-6}}
{\sum_x v_xp_x+\sum_x v_xy_x+10^{-6}}.
\]

不使用平方分母；每份有效样本至少一个valid像素，否则加载器报错。平滑常数和归约不得在不同目标组之间变化，否则Abs-Hard阈值与风险差也会变化。

\[
g^{loss}_{ir}=\ell_{ir}(z_0)-\ell_{ir}(z_1),\quad
g^D_{ir}=D(\hat y_1,y_{ir})-D(\hat y_0,y_{ir}).
\]

hard Dice统一阈值0.5、返回原图坐标后计算；训练loss与Dice单位分开。epsilon_L默认0；Dice显著变化容差epsilon_D=0.005，另报0、0.002、0.01敏感性。

### 6.2 首轮四个训练目标

令d_ir=ell_theta_ir-ell0_ir-epsilon_L。

| 组别 | 精确目标 | 作用 |
|---|---|---|
| D0 | E_ir ell_theta_ir | 普通继续训练 |
| RSI | E_ir ell_theta_ir + lambda E_ir [d_ir]+ | 逐参考相对退化 |
| Mean-Hinge | E_ir ell_theta_ir + lambda E_i [E_r d_ir]+ | 参考均值是否已足够 |
| Abs-Hard | E_ir ell_theta_ir + lambda E_ir [ell_theta_ir-q]+ | 普通绝对难例加权 |

Mean-Hinge必须先在每张图内平均参考再hinge，不得跨batch平均后hinge。RSI的梯度权重为1+lambda I[d_ir>0]；它是相对基准的条件重加权，不宣称新数学原语。

**Abs-Hard的q固定如下：**在共同B检查点、M训练集规范无随机增强视图上，计算每图每参考复合loss；以每图1/N、图内每参考1/m_i为权重，取加权75%分位数。按loss升序累积权重达到0.75的最小值定义。每个完整seed重新计算一次，D阶段固定、停止梯度；不使用val/test选择分位数，不用anchor的逐例退化标签。

Abs-Hard与RSI均有同形式的额外权重，触发依据不同。记录二者激活比例和平均权重；不能仅因加权密度不同就认定相对信息优越。必要时后置加入双方相同的权重均值归一化控制，注明它改变优化尺度。

首轮lambda=1；有限后续网格三种加权方法都用{0.3,1,3}，lambda=0共享D0。不能只给RSI追加权重搜索。

### 6.3 诊断风险项是否在发挥拟议作用

\[
\rho=E_{ir}\mathbf1(d_{ir}>0),\qquad
J_i=E_r[d_{ir}]_+-[E_r d_{ir}]_+
=\frac{E_r|d_{ir}|-|E_r d_{ir}|}{2}\ge0.
\]

J衡量逐参考退化被均值抵消的程度，仅作日志，不加进训练。另记：

`kappa_pm = mean_i I(min_r d_ir < -1e-6 and max_r d_ir > 1e-6)`。

1e-6是数值判别容差，不是Dice工程阈值。输出J均值、分位数、每图值及kappa，不只展示极端病例。

- 每轮对train和val规范eval视图分别记录rho/J；真实增强batch统计另命名。
- 每5轮在预先固定的训练侧诊断batch上记录风险梯度/分割梯度范数比及余弦。只记录，不更新参数或状态；零范数时余弦记NA。
- 记录平均权重、裁剪前梯度范数与裁剪比例，排除单纯有效优化尺度变化。
- 记录loss收益与hard Dice收益的四象限/容差交叉表。

rho近0时增大lambda可能仍缺有效梯度；全部触发时风险梯度局部只是普通分割梯度的lambda倍。J近0会削弱“同图参考得失抵消”解释，但不证明任何内容学习都无效。单参考时J恒0，故ISIC单参考提升不能证明本机制。

### 6.4 性能与损害

\[
G^+=E_{ir}[g^D_{ir}]_+,\quad H^-=E_{ir}[-g^D_{ir}]_+,\quad
H_\epsilon=E_{ir}[-g^D_{ir}-\epsilon_D]_+.
\]

无容差时mean gain=G+−H−。另报：

- any-harm：每图min_r gD < −epsilon_D；
- sign-flip：同图min_r gD < −epsilon_D且max_r gD > epsilon_D；
- 每图最差参考收益及最低10%病例均值；
- 消息RMS、logit更新RMS、mask变化率与正收益保留量。

完全不更新会令H和翻转率为0，不自动算成功。参考数影响any-harm机会，按m=2/m>=3分层，追加每图随机选两份参考的敏感性分析，抽样种子固定。

## 7. 与旧动作控制方案的连接边界

对同图、同参考、同指标、同阈值和同一组实际输出：

\[
g_{\rm full}=D(p_{\rm full},y)-D(p_0,y),\quad
u_a=D(p_a,y)-D(p_{\rm full},y),\quad g_a=g_{\rm full}+u_a.
\]

旧u相对全开，新g相对CNN anchor；分列保存。含正部的损害H不满足这样的相加关系，loss收益也不能与Dice收益混算。

首轮动作是{0,1}；Fixed-Shrink在D0消息上用alpha={0,1/3,2/3,1}。每个alpha真正重算全部受影响tail，不能用输出线性插值代替。中间强度没有自动获得训练分布保证，它是保守替代方法对照。

六动作后置：

1. 先证明还存在可恢复的局部损害，而非为了保留旧方案硬加控制器。
2. Mean和RSI共同接受同样的局部动作支持训练，否则局部关闭可能是未训练状态。
3. 每个冻结消息checkpoint都重算动作输出和监督；不能复用旧消息的效用标签。
4. 使用训练侧留出或交叉拟合训练收益头，不从test取真实动作收益。RSI直接监督本身不需要额外action_fit。
5. 包含最佳固定动作、同容量分类、成本敏感策略及效用回归；标签与计算预算一致。
6. 仅优化平均Dice的策略可能再次伤害部分参考，必须检查是否抵消RSI稳定性。

后置2×2为普通/RSI消息 × 全接收/同族策略。各格统一载体和动作训练支持，逐项报告增量。实际有限动作oracle只界定该候选族，不是任意未来消息变换的上界；不能叠加独立局部oracle冒充联合收益。特征局部关闭造成的区域外变化须通过完整tail复算。

## 8. 训练、预处理和验证预算

| 项目 | 首轮固定值 |
|---|---|
| 输入 | 保比例长边256，居中letterbox至256×256 |
| 图像/mask | 固定双线性及抗混叠配置 / 最近邻 |
| 评价逆变换 | 去padding，logits返回原尺寸，再sigmoid和0.5阈值 |
| 增强 | 同步水平/垂直翻转、90度倍数旋转，轻度颜色扰动仅图像 |
| 优化器 | AdamW，weight decay 1e-4 |
| A学习率 | 编码器1e-4，新decoder3e-4 |
| B / D学习率 | 3e-4 / 1e-4 |
| 调度 | cosine；A warmup5轮，B/D warmup2轮 |
| batch | 有效8；先microbatch4，不足则2并累积 |
| 梯度裁剪 | norm 1.0；AMP先unscale再裁剪 |
| 计算精度 | FP32正确性先通过；AMP之后，loss差与风险FP32 |
| 不同时引入 | GT框、毛发去除、CLAHE、TTA、最大连通域、填洞、阈值搜索 |

所有mask和valid mask使用同一几何增强；不得对不同参考独立变换。首轮无大裁剪/弹性形变。每图min-max概率拉伸会改变决策，不使用。

**验证集选择：**首轮保留完整M val约224图用于开发、checkpoint与预登记有限搜索，避免把H/T1验证子集进一步切碎。它不是独立确认结果。H/T1来源子集仅报告，不据其分数选lambda或epoch。test约451图及其H/T1子集封存评分。

各阶段均按val平均hard Dice选epoch；全部D组相同规则、相同40次epoch检查。再从有限lambda/alpha候选选工作点：

1. 以D0选定checkpoint的val Dice为参照。
2. 保留Dice不低于D0−0.002的候选。
3. 选H_epsilon最低者；并列选Dice高，再选lambda小；Fixed-Shrink并列选较大alpha。
4. 没有合格正lambda的RSI，保留D0并记录未找到有效工作点。

0.002是预定工程容差，不是临床阈值。该规则不自动意味着战胜Abs-Hard、Mean-Hinge或固定缩放，仍要比较其工作点与曲线。

先开发seed17；有限复核seed29沿用配置及超参数，不重新搜索。正式配置锁定后用新seed101/202/303完整重训A/B/D，不只重训最后一层。未来增加路由时另设拟合/校准分工，不能沿用当前验证结果作无限选择。

## 9. 指标、统计和成功范围

### 12.1 T0：文件、划分及实现正确性

### 12.2 T1：普通消息是否值得研究

### 12.5 初步通过、修改与停止条件

以下是继续投入的工程筛查，不是临床或统计显著性保证。

| 观察 | 初步决策 |
|---|---|
| T0任一关键状态/梯度/标签泄漏检查失败 | 停训练，修工程并重跑受影响组 |
| B没有平均正收益且G+接近零 | 优先修基线；不把有害消息作为成功研究样本 |
| RSI相对D0平均Dice下降超过0.002 | 该工作点不合格；只在预登记有限网格内判断其他权重 |
| RSI有合格工作点，H_epsilon低于D0，正收益保留且尾部无明显反向恶化 | 有继续价值，但还要排除简单对照 |
| RSI权衡被Abs-Hard、Mean-Hinge或Fixed-Shrink支配/基本解释 | 分别收缩相对退化、逐参考或内容变化的主张，不直接加模块 |
| H下降但输出几乎等于anchor、G+接近零 | 不更新退化解，不算方法成功 |
| train rho近零而val损害明显 | 缺训练侧有效风险信号，不能靠单纯增lambda解释解决 |
| J/kappa近零，Mean-Hinge等效 | 同图参考抵消不是已被支持的主作用 |
| 只有soft loss改善，hard Dice及边界无支持 | 不宣称最终分割纠错成功 |
| 差异小、配对区间宽或方向不稳 | 结论未定，允许一个预登记seed29复核，不无限搜索 |

“支配”的操作定义：在统一指标下，一个简单对照点Dice不低、H_epsilon不高，且至少一项有实际幅度优势；结合G+和尾部检查。小幅差异与宽区间记未定，不用末位数强行判胜。lambda和alpha选择只依据第8节规则，表外不新增工作点。

两个开发seed都只产生开发证据。若RSI在同等绝对性能下保留正收益并获得简单对照不能解释的损害改善，才进入T3；不要求首轮宣称新的最优成绩。

## 14. 来源与新颖性边界

本版主要整合已有阅读与本地审阅，不声称本轮重新精读所有相关论文。

- [TransFuse论文](https://arxiv.org/abs/2102.08005)与[作者代码](https://github.com/Rayicer/TransFuse)：公开结构及实现参照；自建载体不叫原版TransFuse。
- [IMA官方记录](https://zenodo.org/records/14201693)、[作者仓库](https://github.com/sfu-mial/IMAplusplus)、[图像collection](https://api.isic-archive.com/collections/482/)：数据和来源定义；本地计数以第3节审计为准。
- [ISIC数据](https://challenge.isic-archive.com/data/)、[2018 Task1](https://challenge.isic-archive.com/landing/2018/45/)、[PH2](https://www.fc.up.pt/addi/ph2%20database.html)：任务与数据协议。
- [FAPR预印本](https://arxiv.org/abs/2609.18256)：已有真实Dice下降监督与回退；不是本项目已复现方法，也不标为已正式接收。
- [Predictive Dynamic Fusion，ICML2024](https://proceedings.mlr.press/v235/cao24c.html)：已有预测融合与相对校准，不能简化成弱熵规则。
- [MSE-Nets](https://arxiv.org/abs/2311.10380)、[皮肤StyleSeg](https://arxiv.org/abs/2408.02787)：已有多标注/边界风格方向；完整复现仍待实施。
- [Positive-Congruent Training，CVPR2021](https://openaccess.thecvf.com/content/CVPR2021/html/Yan_Positive-Congruent_Training_Towards_Regression-Free_Model_Updates_CVPR_2021_paper.html)：已有降低模型更新新增错误的选择性蒸馏，需适配对照。
- [Backward-Compatible Prediction Updates，NeurIPS2021](https://papers.nips.cc/paper/2021/hash/012d9fe15b2493f21902cd55603382ec-Abstract.html)：已有何时更新预测的研究，接近旧策略路线。
- [SPriG正式记录](https://doi.org/10.1016/j.inffus.2026.104606)：旧方案已有近邻线索，完整方法未取得，不能宣布排除等价。

本项目试图验证的差异是“对同次更新的多份真实完整参考，使用相对退化约束学习消息内容”。当前判断是存在很近的思想和组件，具体差异值得实验；不是已证明无人做过。

## 15. 交付和首次实验结束时必须回答的问题

本次交付完整v2、首轮测试短版及副本hash；未覆盖v1。真实训练项目、权重与性能尚未交付。

首轮结束时应交付结果表、全部配置/检查点hash、数据版本、失败run、有限搜索记录和go/no-go决定，并回答：

1. 普通消息是否先有值得保留的纠错收益？
2. 哪些损害随参考变化，幅度有多大，是否主要由来源或阈值解释？
3. RSI风险项是否有训练信号，是否实际利用到被参考均值抵消的部分？
4. 同标签同预算下，它是否超出普通加权、先平均后惩罚和固定缩放？
5. 若不能支持，究竟是实现问题、数据不足、没有相应机制，还是方法没有实用增量？

下一次方法决策应依据这些结果，不预先承诺两个创新点，也不以增加模块数量代替机制证据。
