## 三个问题

1. tail放开是否扩大有效纠错：普通目标 U-Mean−F-Mean 的M Dice差=0.000470504、G+差=0.001051354、Hε差=0.000637557。这直接描述tail与message共同适应的变化；同条件复用通过，可作本轮因子比较。
2. RSI是否仍牺牲有用更新：U-RSI−U-Mean 的G+差=-0.007328484、Hε差=-0.006059835；收益保留比=0.461308301。固定U-Mean的all-benefit/all-harm/conflict/other分类在group_decomposition.csv给出同病例变化与总体贡献，不把GT诊断作为推理策略。
3. 简单微调或缩放是否足以解释：U-RSI−U-NoMessage 的M Dice差=0.001471637；U-RSI−训练侧RMS 的Dice差=-0.000855963、G+差=-0.002834562、Hε差=-0.001856314。预登记实用幅度的简单控制支配点：未出现。

这些是实测事实对应的局部机制证据。U组相对U-NoMessage同时改变异构信息和message–tail共同适应，不能单独证明异构特异性；same-tail off输出只是诊断，固定B才是收益anchor。

## 工程与复核边界

工程验收合规：True。固定teacher来自B/best、参数buffers和输出不漂移；student tail独立storage。逐参考CSV绑定checkpoint、teacher、manifest、canonical cache与geometry SHA。原尺寸logits恢复后阈值，BF1与HD95沿用旧实现及已验证精确KD计算，没有TTA/后处理/阈值搜索。

U-NoMessage部署不运行Transformer/message，U-RSI部署只需student一次tail；完整logit插值通常需要teacher和student两次tail。实际训练参数、前向次数、GPU时间和峰值显存在environment/engineering_acceptance/DONE/epoch日志保留，不能把U-NoMessage空算成相同时间。

画册按固定U-Mean受损/改善/冲突及seed17随机规则选择，selection.json列出缺失类别和文件SHA。原图/各真实参考/teacher/各对照及变化同时展示，仅保留用户本地；不同标注和工具流程不等于明确医学错误。

未验证项：独立seed的共同A/B复建、正式独立病例test、跨来源泛化及CNN自消息/近邻算法归因。没有自动启动seed29、101/202/303、额外λ/模块/α网格或ISIC训练，没有上传权重。

本轮结果与所有检查的SHA见delivery_manifest.json；preregistration.json绑定任务书与固定筛查规则。若状态CANDIDATE，只建议独立确认；其余状态按decision.json结束当前自动预算，不扩展实验。

epoch 时间包含该轮训练、canonical 诊断、验证及必要检查，记录点位于当轮日志和 checkpoint 保存之前。DONE wall 从训练阶段循环开始累计，含随后保存与结束哈希开销，排除之前的模型构建和数据预载；外层 phase 覆盖命令构建、预载、完整训练和命令退出。这些计时范围不能混用。

U-NoMessage 最先准备本轮 canonical 缓存并预载；这部分发生在 DONE 训练阶段计时开始之前，计入外层 phase。其 phase−DONE 为 476.12 秒，包含构建、首次缓存准备/预载等总开销，未单独计时的部分不能全部精确归因为缓存。后两组复用了已准备的缓存，不能据此宣称 U-NoMessage 的训练算法或部署更慢。

U-NoMessage 只训练 student tail，分割路径真实跳过 Transformer/message；U-Mean/U-RSI 训练 message 与 student tail。训练/参照诊断共同支付固定 teacher tail 与 student tail 两次解码；普通 student 部署仅一次 student tail，U-RSI 部署无 GT/teacher 输入。完整 logit 更新插值通常支付 teacher 与 student 两次 tail，不与旧 feature shrink 混算。

峰显存是各 epoch 实际 `torch.cuda.max_memory_allocated()` 的最大值，包含当时存活张量，不是 reserved 显存或整卡容量。
