# MambaVision-S 的浅层补充分支实验

ISIC 2018 的同一份 867 张测试图，按图计算前景 Dice 后等权平均。种子 42。沿用同一个第 39 轮 SDI 最佳权重，原弱残差增益在四组的训练和推理中均启用。四组各追加 40 轮，相同增强顺序、优化步数和冻结策略，均由开发集选到续训第 19 轮。原模型作为独立零更新参照，未参与四组在 40 个续训 checkpoint 之内的选模。

| 方法 | 测试逐图 Dice | 已知关联过滤后的 814 张 |
|---|---:|---:|
| 原生 UPer64（既有参照） | 89.5654% | 89.4125% |
| 原 SDI 四路乘积（既有参照） | 89.7751% | 89.6234% |
| 原 SDI 弱区残差乘 2（本次重新重放） | 89.8319% | 89.6784% |
| 续训，无新分支 | 88.2675% | 88.1190% |
| 续训，全图 F1/F2 | 88.3070% | 88.1584% |
| 续训，等面积错位 F1/F2 | 88.2838% | 88.1350% |
| 续训，F3/F4 同时偏弱处补 F1/F2 | 88.2559% | 88.1073% |

三个新增分支具有相同的 115,136 个参数。弱区由两张对齐后深层特征图各自跨通道均方根低于图内中位数的位置求交集。真实弱区比同预算全图分支低 0.0511 个百分点，比等时无分支低 0.0116 个百分点。开启既有弱区分支相对同一组权重关闭它提高 0.0472 个百分点，支持该分支能够改变预测。该干预不评估重新训练一个模型的收益。无分支也比续训前低 1.5644 个百分点，共同训练设置对结果的影响超过三个分支之间的差距。

762 张开发图的额外诊断中，训练后门控覆盖全部像素的 27.56%，进入门控的像素中 89.51% 属于标注背景。用旧模型的预测定位严重内部漏分，在两类内部区域均有足够像素的 182 张图上，真实门控平均覆盖 57.43% 的严重漏分和 4.75% 的正确内部前景。同一训练权重开关浅层分支后，没有开发像素从关闭时前景概率小于 0.1 的深部真实前景直接变为开启时概率至少 0.5。三张固定病例在 gate_cases.png。

另外在开发图上固定无分支模型的参数，互换续训前后的 BatchNorm 运行统计。恢复原统计能找回部分下降，仍低于原权重和原统计的组合；不能据此归因测试集下降的原因。详见 bn_factorial_dev.json。单种子，既有测试集已经多轮比较，尚未做独立外部确认。

训练与评估脚本在本目录。runs 下保留四组最佳权重、锁定记录、历史、逐图测试结果和已知组配对区间。图像逐份核对哈希，同一模型的 867 份历史测试逐图 Dice 均已重放。
