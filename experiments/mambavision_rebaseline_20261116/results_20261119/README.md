# MambaVision-S 皮肤病灶分割实验更新（2026-11-19）

在同一套 ISIC 流程中，冻结已选权重并逐图计算前景 Dice。测试集共有 867 张，按既有规则剔除已知或保守的跨组关联后剩 814 张。训练种子和项目先前对测试集的重复使用限制了外推结论。

| 实验输出 | 867 张测试逐图 Dice | 814 张敏感性分析 |
|---|---:|---:|
| 原生 UPer64 | 89.5654% | 89.4125% |
| UPer64 + 四尺度 SDI 乘积 | 89.7751% | 89.6234% |
| SDI 弱区残差乘 2 | **89.8319%** | **89.6784%** |
| 独立训练的原生 UPer64 与上行模型等权概率平均 | 89.7906% | 89.6393% |

当前保留单模型 SDI 弱区增强。普通 UPer64 和 SDI 各自的 867 份历史逐图测试 Dice 均在最终集成对照中复现。表中分数是本组实验的结果。
