# SDI 的占比信息与模型互补性

本次只对训练和开发图作新的推理。原 SDI 弱区增强模型记为 A；F4 占比旁路取真实训练到第 40 轮的 C，在上一轮开发集选模中仍由第 0 轮胜出。所有比较共用 762 张开发图，每图 8×8 个互不重叠的 32×32 格子。格内同分且跨选取阈值时使用均匀打破并列的期望正确数，未用真值打破并列。

## 占比与像素排序

| 每格前景占比平均绝对误差（百分点） | 全部 48,768 格 | 11,888 个前景/背景混合格 |
|---|---:|---:|
| A，二值分割前景像素比例 | 4.73 | 14.57 |
| A，前景概率的格内均值 | 4.76 | 14.36 |
| C，第 40 轮辅助头直接预测 | 5.38 | 16.36 |

C 在全前景格略优于 A 的二值比例（5.69 对 5.88 个百分点），在纯背景和混合格变差。给 A 每个格子的真实前景数，只沿用 A 的格内排序，错像素数由 2,427,943 降至约 587,802，减少 75.79%；758 图减少，4 图增加。这是用人工标注提供条件的诊断，不是部署成绩或任何方法的通用上界。若改成按 C 的辅助预测分配数量，较 A 净增约 329,200 个错像素。额外试了一个在 1,886 张训练图上按占比均方误差拟合的固定混合系数，C 比重 0.4885；开发图上也净增约 118,878 个错像素。两模型的训练预测用于拟合，该系数没有独立校准集的保障。

对比 **主分割** 的变化，把 A/C 的格内排序和 A/C 主分割阈值产生的每格数量交叉组合。对两种置换顺序取平均，净增的 149,165 个错误中，数量变化贡献约 +150,516，排序变化贡献约 −1,351。此为对输出的精确代数分解，依赖所选网格和错像素指标，不是内部网络参数的因果归因。相对 A，C 产生的假阳性多 306,969，假阴性少 157,804。对当前 F4 方案，更直接的解释是它扩大了前景，数量修正总体方向不佳。

## 另一份预测能提供多少互补信息

下表均以 A 为参照，正数表示多错，负数表示少错。两套完整模型均为 MambaVision-S，同训练种子，既有同协议组，但后两级编码器和解码器分别训练。

| 固定对照 | 762 张开发图合计错像素变化 |
|---|---:|
| A 与水平翻转再对齐的 A，两张概率等权平均 | +1,854 |
| A 与同一份 A 编码特征送入既有普通 UPer64 头后的概率等权平均 | +11,190 |
| A 与独立训练的完整原生 UPer64 模型，两张概率等权平均 | −42,475 |

原生 UPer64 单独使用比 A 少错 36,509，故双模型相对它只少错 5,966，平均每图少 7.83 个。按已知开发病例组配对自助抽样，融合减原生 UPer64 的每图错像素 95% 区间是 [−48.65,+45.12]。融合减 A 是每图 −55.74 个，区间 [−109.93,−12.27]。单一种子并已反复检查开发集，不足以断言融合能超过两个单模型。双模型相对 A 的净改善中，每格数量项约 −39,394，排序项约 −3,081。共享编码器的交叉移植可能受到旧解码头与新特征失配影响，不能推出双编码器不可替代。水平翻转平均在更多图上有少量改善，但合计像素错误增加，显示指标权重差异。

眼下优先保留当前 SDI 测试参照；后续若验证互补性，先用锁定的原生 UPer64 与 SDI 检验固定 1:1 概率平均能否稳定优于两端。若通过，再在独立训练/校准协议下判断能否用一个编码器吸收互补收益。无须先加新的深层面积头。源码、协议、逐图数据及诊断 JSON 与本记录同目录。
