# MambaVision-S 窗口对照与冻结特征诊断

## 同条件窗口消融

两组使用相同的 ImageNet-1K 初始化、原生 UPer64、256×256 输入和种子 42，微调 Stage 3/4。原生对照沿用既有 100 轮权重，本轮对齐窗口从头微调 100 轮。训练 1886 张、开发 762 张、测试 867 张。用开发集逐图 Dice 最高的最早轮次锁定权重，测试阈值固定为 0.5。原生对照重放的全部 867 个逐图分数与既有记录吻合。

| Stage 3/4 窗口 | 最佳轮次 | 测试逐图前景 Dice | 814 图敏感性分析 |
|---|---:|---:|---:|
| 14/7 | 39 | 89.5654% | 89.4125% |
| 16/8 | 39 | 89.8418% | 89.6684% |

867 图配对差为 +0.2764 个百分点。按既有病例关联组自助抽样的 95% 区间为 [+0.0187, +0.5234] 个百分点。测试集在项目早期已被多次使用，区间仅反映这组图像的抽样波动。改变窗口会同时改变填充、窗口连通范围和扫描序列长度。

## 冻结模型的线性读出

读取原生 14/7 UPer64 最佳权重中的 Stage 3 block 3 和 Stage 4 block 2（块序号从 0 开始），恢复图像坐标、剔除填充。标签为各网格单元被前景覆盖的面积比例。普通最小二乘使用每张训练图固定抽取的 32 个位置拟合。下表是 762 张开发图全部有效位置的覆盖率均方根误差，越低越好。

| 读出位置 | Stage 3 | Stage 4 |
|---|---:|---:|
| SSM | 0.27409 | 0.16249 |
| 非 SSM | 0.27434 | 0.16230 |
| 投影前拼接 | 0.24686 | 0.15354 |
| 投影后 | 0.24679 | 0.15362 |

相同阶段的拼接读出与投影后读出具有相同输入宽度。该诊断考查固定特征中可由线性模型读出的局部面积信息，分割网络权重在诊断中冻结。模型选择曾使用这 762 张开发图。
