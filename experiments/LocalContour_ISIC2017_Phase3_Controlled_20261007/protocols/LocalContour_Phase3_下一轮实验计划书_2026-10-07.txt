说明：
本文件是下一轮计划，不是已经完成的实验报告。除“现有证据”部分外，本文的模型配置、训练预算、阈值和验收条件均为待执行的协议建议。正式运行前，将最终配置、数据清单与代码版本一并锁定；修改协议必须新增版本，不能覆盖历史结果。

本轮不以“想办法让 Transformer 赢”为目标。需要回答的是：在相同初始分割、相同候选和相同输入信息下，跨节点通信是否提供了额外、稳定、值得付出计算成本的收益。

======================================================================
0. 执行摘要：这轮只解决什么问题
======================================================================

0.1 主任务

第一，统一 DP 与普通候选选择器的校准集和读出集，排除统计范围和选参流程不一致。
第二，让局部模型获得比原来 8 epoch 更充分的训练机会。
第三，增加“单节点修补器”，与 Local8、Medium32、Global 共享相同上游评分、输入、残差结构和近似参数预算。
第四，检查全局模型的优势究竟来自更好的候选判断，还是主要来自更少、更小的移动。
第五，只有上述比较成立，才进入未参与开发的数据上的锁定确认。

0.2 最小必做模型

S64：充分训练的 StrongLocal，宽度 64。
S96：充分训练的 StrongLocal-Large，宽度 96。
N0：单节点残差 MLP 修补器，无新增跨节点通信。
T8：两层局部注意力修补器，每层圆周范围 ±8。
T32：两层中程注意力修补器，每层圆周范围 ±32。
TG：两层全局注意力修补器。

N0、T8、T32、TG 均接在同一随机种子的 S64 之后，使用同一份 S64 分数缓存。
主种子固定为 17、23、42，共 6 类 × 3 种子 = 18 次模型训练。
CNN、零位重建、位移惩罚、DP、Oracle 不额外计为模型训练。
调试失败后的重跑属于额外运行，必须如实登记，不能计作独立重复。

0.3 暂缓事项

本轮不扩大 Transformer，不增加搜索半径，不换候选表示，不增加新的损失组合，不做端到端联合微调，不把显式 gate 扩展成第二条主线。
不重做大规模文献综述，不预先声称方法创新成立，不以 Oracle 数值制定 Transformer 必须达到的目标。

0.4 默认执行顺序

P0：冻结协议、数据角色与源码；补充测试。
P1：能够恢复旧权重时，先公平重评 Fixed 存档；不能恢复时，明确跳过该项。
P2：seed17 小规模联调与资源测量；通过后执行完整受控重训。
P3：仅在 cal50 选参；所有配置锁定后一次性生成 dev100 主读出。
P4：完成两项主比较、机制分析和风险分析，给出 GO / HOLD / REDIRECT。
P5：仅在进入条件满足后，建立来源清晰的完整管线并进行独立测试。

1. 当前证据与本轮出发点
======================================================================

1.1 已知修复状态

Fixed 版已修复普通选择器与门控选择器的 KEEP 标签索引问题；当前 R32 稠密布局为 65 个候选，零位索引为 32。
新增 Local 网络已改用逐像素通道分组归一化，不再通过新增整图 GroupNorm 交换空间统计；冻结 CNN 特征本身仍可能含有全图信息。
上一轮复核中，7 项合成测试通过，存档主表与逐图 CSV 的重算一致。但公开包没有权重及完整候选缓存，不能把这些检查等同于重新训练和真实图像推理的独立复现。[S1、S2]

1.2 当前同一 dev100（历史名称 val100）上的三种子均值

原 CNN：                 Dice 85.3051%，BF1 51.3784%。
StrongLocal：            Dice 85.3925%。
StrongLocal-Large：      Dice 85.3995%。
Local8：                 Dice 85.4412%。
Medium32：               Dice 85.5127%。
Global：                 Dice 85.5760%，BF1 54.0349%。

Global 相对 CNN 的 Dice 增益约 +0.2710 个百分点；相对 Local8 约 +0.1349 个百分点。
但 Global 相对 Local-Large、Medium32 的探索性配对区间仍跨过 0；对 Medium32 只在一个种子上胜出。
这些均为重复使用的开发数据，不是独立测试结果。[S1 第四节]

1.3 不能跳过的四个问题

问题 A：DP 的原发布均值来自 val150，主表来自 val100，且两者选参数据不同。必须统一，不能通过混读均值宣布 DP 失败。

问题 B：去掉位移惩罚后，存档 Global 的 Dice 约 83.6444%，低于原 CNN。当前有效方法是“学习式重评分 + 保守位移约束”，不能把全部收益解释为网络独立学会正确修补。

问题 C：两种 Local 模型的六次训练，最佳 checkpoint 都在预算最后的第 8 轮；尚不能说强局部基线已充分训练。

问题 D：Global 完整系统还包含上游 S64 评分器。只拿 refiner 参数量对比单阶段局部模型，不能完成系统容量控制。[S1 第五、六、九节]

1.4 当前机制线索

事后分组显示，收益主要集中在原 CNN Dice 较高的图像。Global 的移动幅度小于局部大模型，可能主要改善稳定性与小尺度边界一致性。
但“初始 Dice 高低”不是“局部候选是否存在歧义”的直接指标，下一轮必须建立候选层面的分析。[S1 第七节]

1.5 研究命题

在固定 CNN 初始分割和局部候选的前提下，新增跨节点通信能否：
（1）超过同输入、近似同容量的单节点重评分；
（2）在简单闭环平滑之外继续提供收益；
（3）在相近修改预算下，提高修补准确性或减少有害修改；
（4）将上述收益保留到未参与开发的数据上。

2. 假设与预先确定的解释边界
======================================================================

H1：跨节点信息有独立增益。
直接证据：TG 与 N0 使用相同上游、相同输入和相同后处理，TG 更好。
仅 TG 优于单阶段 S64，不足以支持 H1，因为额外网络容量和二次训练也能解释差异。

H2：跨节点学习不完全等价于简单位移平滑。
直接证据：在共同 DP 协议下，TG 仍比强局部或 N0 基线更好。
若 N0+DP 或 S96+DP 已达到相近结果，应承认简单方法仍有竞争力。

H3：整条轮廓通信优于较长局部窗口。
直接证据：TG 稳定超过 T32，且收益值得额外成本。
TG 优于 T8 但不优于 T32，只支持扩大上下文范围，不支持“全局注意力不可替代”。

H4：收益不只是更少移动。
直接证据：在 cal50 确定的相近移动预算下，TG 仍有更高修补精度、更低有害修改率或更好的分割指标。
该对照仍不能单独证明模型理解了病灶语义，应结合歧义节点分析。

H5：有限训练预算没有人为压低局部基线。
直接证据：增加训练预算、统一 checkpoint 规则后，主要结论仍然成立。
若强局部模型追平，调整研究叙事，不继续把其旧的 8 epoch 结果当作核心对照。

不要求各模型构成预设的严格单调序列。
不把“区间跨 0”自动解释为“完全没有作用”，也不把“均值最高”解释为稳定优势。

3. 三个证据层级：必须分开命名
======================================================================

A 层：Fixed 存档公平重评
复用 Fixed 已训练模型，纠正校准与读出流程。用于定位上一轮比较中的不公平因素。
这些模型曾使用全部 val150 选择 checkpoint，因此该层不可能变成独立验证。

B 层：新一轮受控开发实验
重新训练本轮评分器与修补器，明确 fit / stop / calibration / readout 的用途。
虽然避免新增的角色混用，但数据此前已被观察，部分冻结上游也存在训练身份不完全清晰的问题。仍称开发实验。

C 层：独立确认
只有在完整管线训练身份清楚、测试数据没有参与开发、模型与规则冻结后，才能使用这一名称。
“本轮没有读测试 GT”本身不够，必须核对 CNN、边界头、评分器、refiner 及历史模型选择的全部暴露关系。

A、B、C 分别建表，不混合均值，不把不同 CNN 初始分割的结果放进同一配对分析。

4. 数据协议：哪些数据允许做什么
======================================================================

4.1 B 层默认划分

沿用包内官方清单的 2000 train、150 val、600 test 身份信息。[S3]
在官方 train 的 2000 张内部生成本轮 fit1800 / stop200。
沿用 Phase1 已存在的 calibration50 / locked_verification100 身份列表，将后者统一改称 dev_readout100，简称 dev100。

角色                 默认数量       允许用途
fit1800              1800           训练本轮 S64/S96 和所有 refiner，计算训练统计。
stop200              200            早停、checkpoint 选择、统一训练诊断。
cal50                50             选 alpha、lambda、模型族和诊断阈值中指定的校准量。
dev100               100            本轮配置冻结后的开发读出、统计和病例分析。
official_test600     600            P5 以前不生成预测、不评分、不查看病例。

默认数量建立在图像级划分上。若能获得可靠的患者/病灶分组，优先按组划分并保持无跨组泄漏，数量允许略偏离目标；必须记录实际数量，不为了凑整拆开同一组。

4.2 划分生成规则

先使用可核实的分组 ID；缺少分组 ID 时，以 image_id 为单位。
按 SHA256("LC-P3-v1|" + group_or_image_id) 的十六进制字符串排序，确定接近目标 200 张的 stop 子集，其余作为 fit。
同一数据划分适用于全部模型和全部训练种子；种子只改变训练随机性，不改变数据成员。
无分组 ID 时只能声称图像 ID 不交叉，不能声称患者级独立。

cal50/dev100 必须从已有 assets/val_split_seed17.csv 的真实角色恢复，不能重新挑选更容易得到正结果的 100 张。
若该清单缺失，先恢复并核对；不要静默重划后继续使用旧名称。

4.3 冻结上游的限制

B 层允许为了节约计算，继续使用 Fixed 的冻结 CNN 和边界头，但需要记录它们是否可能见过 stop200、cal50、dev100 的 GT。
本轮的 fit/stop 分离，仅约束本轮新训练模块，不能消除旧冻结模块的历史暴露。
所有本轮新训练的 S64/S96/refiner 都只用 fit1800 做梯度更新。
不能把之前用全部 2000 张训练的 S64 直接接到 B 层后，再声称整条新增训练链路没见过 stop200。

4.4 程序隔离

训练入口只能接收 fit 与 stop 清单，不能通过固定 split=='val' 自动读入全部 150 张。
校准入口只能接收 cal50，不能载入 dev100 GT。
开发读出入口只能接收已经写定的 chosen_config.json，不得在读出过程中自行取最大值。
测试入口需要 final_lock.json 明确授权。

将推理数据视图与标签数据视图分开。普通推理函数不接收 gt、gt_distance、oracle_label 等字段。
GT 只进入训练目标、允许的校准评分、离线评估及 Oracle，不能进入候选有效性判断或普通模型的回退路径。

4.5 必须保存

splits/fit.txt、stop.txt、calibration.txt、development_readout.txt、test.txt。
每份清单的 SHA256、图像数、分组数、角色交集检查结果。
每个 checkpoint 的 fit_ids_hash、stop_ids_hash 和上游 checkpoint_hash。
数据访问日志与角色断言；日志是审计证据，不是历史未泄漏的绝对证明。

5. 冻结的表示与实现约定
======================================================================

5.1 主实验固定

输入分辨率：256×256，图像和标签变换与 Fixed 保持一致并记录插值方式。
轮廓节点：256。
法线搜索半径：32 像素。
候选偏移：-32、-31、…、0、…、31、32，共 65 个。
原始布局的 zero_index：32；所有模块从统一 candidate_layout 读取。
CNN、边界头在 B 层冻结；本轮不联合微调。
主实验不新增图像增强、法线更新、多轮修补和连续位移回归。

这些是围绕 CNN 初始轮廓的固定几何候选，不能称为本轮新学会的 CNN 自适应候选生成器。

5.2 不因 GT 删除样本

有无轮廓、候选是否在图像内、数值是否合法等判断，只能使用预测与几何。
无轮廓图像按原始 CNN 输出进入分割主表；不能因为难修或候选不可达而删除。
GT 法线交点是否唯一等条件，只能用于相应的离线诊断分母，不得决定普通推理时是否处理该图。

5.3 轮廓重建

B 层先保持 Fixed 重建策略不变，保留其他连通区域及孔洞的规则也保持一致。
同时报告原 CNN 与 G1_zero_reconstruction。全选零位后，栅格化结果可能与原掩码略有差异，不把这部分差异记成学习收益。
主表同时给出相对 CNN 与相对 G1 的改变量。
若未来采用“全部 KEEP 就直接返回原掩码”，必须作为独立协议改动，一致应用全部方法，不能只给某个模型使用。

5.4 缓存与数值精度

同一个种子、同一实验组中的候选坐标、valid mask、CNN 特征和 S64 分数必须逐文件同哈希。
特征缓存精度沿用明确版本；本轮新导出的候选 logits 默认保存 float32，防止小分数差异在再量化时丢失。
这与 Fixed 某些 float16 分数缓存存在数值路径差别，B 层必须对全部模型统一；A 层原样重评不得悄悄改存档精度。
缓存元数据记录形状、dtype、生成代码、源权重、图像角色、候选布局和 SHA256。
没有权重和真实候选缓存时，不能只凭日志声称重新推理完成。

6. P0：训练前测试与放行条件
======================================================================

先运行已有 7 项修复测试，再增加以下检查。新增测试名称是待实现要求，不代表仓库已经提供相应入口。

T01 索引与目标：
65 候选、零位 32；最近候选距离超过 4 像素时监督 KEEP；普通损失和 gate 历史回归测试均覆盖。

T02 无效候选：
无效候选目标概率为 0，推理不可选中，无效 logit 的屏蔽不能造成 NaN；零位有效性必须通过断言。

T03 输入隔离：
替换或移除推理数据视图中的 GT，不应改变候选、局部特征、网络 logits 和普通预测。GT 缺失时普通推理应能完成。

T04 单节点隔离：
在 eval 模式固定目标节点的 44 维 context、65 维分数和 valid，任意修改其他节点；N0 该节点输出应不变。
该测试只检验新增 refiner，不检验冻结 CNN 或预计算几何本身的像素级感受野。

T05 注意力范围：
T8/T32 的每层圆周 mask 分别允许 17/65 个节点，TG 允许 256 个；0 与 255 的邻接不能断开。
固定输入后，两层 T8 的可达节点最多为 33，两层 T32 最多为 129。验证超出依赖范围的输入扰动不会影响目标节点。
不要强制要求任意一次远处扰动都使 TG 改变；全局可访问不等于模型必然使用该信息。

T06 归一化：
逐像素通道归一化不产生额外跨空间统计依赖；N0 的 LayerNorm 只沿单节点通道维操作，禁止跨 N 维归一化或池化。

T07 参数与有效计算：
打印新增参数、完整可训练模块参数、实际收到梯度的参数、前向时间与峰值显存。
不能用挂上却不参与前向的参数凑容量，也不能用 self-only attention 中退化的 Q/K 参数充当主要容量匹配证据。

T08 DP：
小规模随机闭环问题与穷举目标值一致；终点到起点的代价不遗漏。
lambda=0 时目标最优值与独立逐点选择一致；同分时使用明确定义的保持优先规则。
若状态为加速而重排，输出必须映射回原始候选索引，不能改变 ZERO_INDEX 的标签语义。

T09 重建与指标：
相同掩码、空掩码、单像素、平移轮廓、多连通区域、孔洞等测试。
固定 BF1 容差、HD95 定义、空集策略、宏平均与微平均口径。

T10 角色与缓存：
fit/stop/cal/dev/test 角色互斥；训练不能打开 dev/test 评分入口；上游哈希不符时立即退出。
所有涉及样本数的断言从实际 manifest 读取，不能到处硬编码 2150 或 2000。

放行条件：全部必做测试通过，失败用例保留。单纯出现一个新的 PASS.json，不足以替代测试输出和实际数据检查。

7. P1：旧 Fixed 模型的公平重评（可恢复时先做）
======================================================================

7.1 目的

不改变旧权重，回答：在同一 cal50 选参、同一 dev100 读出后，旧 Local+DP 与 Global 的差距是什么。
该项用于解释历史结果，不用于证明新模型的泛化能力。

7.2 执行条件

需要 Fixed 的真实 checkpoint、对应冻结 CNN/边界头、同源特征与候选，或可按相同版本完整重建它们。
此前发布包不包含这些权重，且报告称已清理部分可重建缓存。[S2]
如本地训练环境仍保存权重，核对 SHA256 后恢复。
若权重不可得，标记 ARCHIVE_REEVALUATION_UNAVAILABLE，直接进入 B 层受控重训。
重新训练出来的新权重不能冒充“旧权重公平重评”。

7.3 流程

（1）复核旧 alpha 曲线的 cal50 选点和 dev100 读出。
（2）从旧分数重新生成 DP 在 cal50 上的候选参数结果。
（3）只用 cal50 决定 alpha/lambda；固定后在 dev100 输出逐图指标。
（4）同一表内列 CNN、G1、S64、S96、T8、T32、TG 的同范围结果。
（5）明确写入这些旧模型的 checkpoint 曾由 val150 选择。

只保存“在全部 val150 挑好的一个 DP 配置”的逐图结果，不足以重新选出 cal50 最佳 DP；必须有各候选配置结果或重新推理。
不能把旧 val150-selected DP 结果裁成 dev100，就称为公平校准已完成。

8. P2：模型组与最重要的新对照
======================================================================

8.1 S64 / S96：充分训练的局部模型

沿用 Fixed 的 StrongLocal。
S64 width=64，约 137,217 参数。
S96 width=96，约 291,841 参数。
输入包括冻结 decoder 特征、RGB、CNN 概率、边界概率以及候选几何信息。
使用逐像素通道分组归一化。新增卷积在冻结特征图上的窗口与 Fixed 一致。
这两个模型不是“原始像素严格局部可见”的系统；本轮也不作这种宣称。[S4]

8.2 N0：单节点残差 MLP（本轮新增、必须做）

对节点 i，只读：
context_i：44 维。
local_scores_i：S64 的 65 个候选分数。
valid_i：只用于与 Transformer 一致的候选分数归一化及输出屏蔽。

复用 Fixed NodeRefiner 中的分数归一化函数，并抽成公共函数。不得为 N0 单独换归一化。
输入总维度保持 44+65=109；不额外给某一个模型加入 valid embedding 或更多 RGB 特征。

推荐结构：
Linear(109→128)。
两个逐节点残差块，每块为：
  LayerNorm(128)
  Linear(128→512)
  GELU
  Dropout(0.1)
  Linear(512→128)
  Dropout(0.1)
  加回该节点的残差。
输出 Linear(128→65)，权重和 bias 初始化为 0。
最终分数 = 与 Transformer 相同的归一化 S64 分数 + 残差输出。

按上述带 bias 的线性层和带仿射参数的 LayerNorm 计算：
N0 参数约 286,401；Fixed refiner 为 287,425，差约 0.36%。
接上 S64 后，N0 完整新增模块约 423,618 参数，TG 约 424,642。
这些是结构推算值，实际实现必须重新打印核对。[S5 与本计划结构计算]

不得使用跨节点卷积、全序列池化、跨节点归一化、节点信息拼接或 attention。
本对照只取消新增的跨节点计算。其 44 维输入含冻结 CNN、轮廓坐标和几何信息，不能称其完全没有整体先验。

8.3 T8 / T32 / TG

沿用同一个 NodeRefiner：2 层、dim=128、heads=4、feedforward_dim=256、dropout=0.1、零初始化输出头。
三者只改变 attention mask，其他计算完全相同。
同一个种子中，复制相同的初始参数张量，再设置不同 mask；数据顺序、增强和优化器设置一致。
T8 每层 ±8；T32 每层 ±32；TG 全连接。不要把层数传播后的范围误称为单层窗口。
N0 与三者输入相同、输出接口相同、标签相同、残差分数接口相同。

8.4 统一上游

每个种子先训练一次 S64 并选择 checkpoint，然后冻结并导出分数。
该种子的 N0/T8/T32/TG 必须读取这同一个 S64 分数文件，不允许为某个 refiner 选择表现更好的上游种子。
S96 作为独立强局部基线，不替换其中某一个 refiner 的上游。

8.5 不把“完整系统成本”省略

参数表分别列：冻结 CNN/边界头、新增上游 S64、refiner、系统总参数。
训练成本列：上游训练时间 + refiner 训练时间；共享成本在单个系统估算中仍应计入，批量实验可另列共享摊销。
推理成本包含候选构建、S64、refiner、后处理和重建；同时提供不含缓存 I/O 的纯计算时间。
S96 与 TG 并非完整系统等参数，但 N0 与 TG 已提供更直接的两阶段匹配对照。
若后续论文还强调“优于同总容量单阶段 CNN”，再补相近总容量的局部模型；不作为当前最小包的先决条件。

======================================================================
9. 训练协议：解决原来 8 epoch 的不足
======================================================================

9.1 默认预算（须在正式运行前锁定）

种子：17、23、42。
S64/S96：AdamW，初始学习率 1e-3，weight_decay=1e-4，batch_size=4。
N0/T8/T32/TG：AdamW，初始学习率 3e-4，weight_decay=1e-4，batch_size=16。
梯度裁剪：范数 1.0。
最大 40 epoch，最少训练 12 epoch，早停 patience=8。
有效改善阈值：stop200 的平均候选交叉熵降低超过 1e-5。
默认固定学习率，避免这轮同时引入新的学习率搜索；模型内混合精度设置统一并登记。
以上是本轮默认配置，不代表已被验证为最优。

同一类 refiner 的训练预算和候选 checkpoint 数相同。卷积评分器与 refiner 的 batch 不同，不能仅凭同 epoch 声称等 FLOPs；必须记录样本遍数、更新步数与实际耗时。

9.2 checkpoint 选择

只按 stop200 上同一定义的 soft candidate CE 选择 checkpoint；严格同分时取较早 epoch。
cal50 不参与早停，dev100 不参与 checkpoint 选择。
保留第 8 epoch 快照和日志，用来描述延长训练的影响；该快照不用于在 dev100 上二选一后替换主结果。
不把所有 checkpoint × alpha × lambda 在 dev100 上扫一遍再找最好组合。

若达到 40 epoch 后仍明显改善，标记 TRAINING_BUDGET_EDGE。
此时不能声称该基线已充分收敛。需要增加预算时，先在尚未读出 dev100 的条件下修订统一规则，记录所有旧运行，再进行同类模型补跑。
不允许只延长落后的某个 Transformer，或只因 dev100 不理想才修改训练长度。

9.3 训练标签保持 Fixed 不变

对节点 i 的有效候选，d_ik 为候选到完整二维 GT 边界的距离。
若 min_k d_ik ≤ 4 像素：q_ik ∝ exp(-d_ik / 1.5)。
否则：q_i 为 zero_index 的 one-hot。
无效候选概率为 0，节点损失为候选 soft CE。
GT 不可达判断在这里属于监督规则，不允许用于推理时按 GT 决定 KEEP。

暂不新增 L_keep、门控损失、连续 offset 损失或可微栅格化损失。
当前标签并不直接最大化 Dice，也不保证是最终最优目标；先固定它以隔离信息范围问题。

9.4 训练诊断

每轮保存 fit/stop CE、候选准确率、梯度范数、无效目标数量、KEEP 目标比例及实际更新步数。
对无轮廓图像和无有效统计分母的情况明确记录；不能用跳过训练节点的规则删除评估图像。
S64 在 fit 上产生的是训练内分数，stop/cal/dev 是未用于本轮 S64 梯度更新的分数。记录两者分数尺度与置信度差异。
这种两阶段训练内/训练外分布差别不是自动的 GT 泄漏，但可能影响堆叠模型泛化；所有 refiner 必须处于同一条件。严重时再另立交叉拟合实验，不在本轮暗中只给 TG 使用。

9.5 调试到完整运行

先用 fit 中固定的少量图像跑通前向、反向、缓存与评估，不输出 dev100 比较。
之后运行 seed17 的全部六类模型和 cal50 资源测试。
源码与配置不变、测试通过的 seed17 可以计入三种子正式结果。
若中途修改影响预测或训练的代码，旧 seed17 作废并归档；不得将修前修后的种子拼成一个三种子表。
完成 17、23、42 全部模型及校准后，才统一生成 dev100 主读出。

======================================================================
10. 后处理与校准：alpha、DP 必须走同一套流程
======================================================================

10.1 普通保守选择：后缀 _A

每个节点：
k_i = argmax_k [z_ik - alpha × |s_k|]。
无效候选不可选；s_k 是实际偏移，不以索引差代替一般布局中的物理偏移。

alpha 网格固定：
{0，0.02，0.05，0.1，0.2，0.5，1.0，2.0}。

每个模型、每个种子在 cal50 独立选择 alpha，以 cal50 图像宏平均 Dice 为首要标准。
报告原始 alpha=0 结果，不只报校准后的最佳点。
不同模型 logit 尺度不同，同数值 alpha 不自动意味着同样强的保守约束；T 与 N0 的公共分数接口应尽量一致。

10.2 闭环 DP：后缀 _D

保持现有目标形式：
E(k_1,…,k_N) = Σ_i [-z_i,k_i + alpha |s_k_i|]
                + lambda Σ_i (s_k_i - s_k_(i+1))²。
k_(N+1)=k_1，必须包含最后节点与首节点的闭环项。
可加不改变最优解的逐节点常数稳定数值，不能额外引入只给某个模型使用的代价。

lambda 网格固定：
{0，0.002，0.01，0.05，0.2，0.5，1.0}。

alpha 使用与 _A 相同的 8 个数值。完整联合网格为 8×7=56 个配置。
S64、S96、N0、T8、T32、TG 的 _D 使用同一搜索空间和选择标准。
DP 比 _A 多一个超参数、更多选参尝试，必须如实报告；不要声称两类后处理搜索预算相同。
关键匹配比较分别在 _A 对 _A、_D 对 _D 内进行。

10.3 候选剪枝不能成为隐藏变量

本轮最终 DP 主对照默认使用完整 65 个候选，其中出界候选以无穷大代价屏蔽。
这避免把“按局部分数提前删除正确候选”误判为 DP 无法利用结构。
完整闭环实现可枚举首状态，计算量比开放链更高；先在按 ID 哈希选定的 10 张 cal50 图像上做计时和内存测试，不根据这些图的性能挑选样本。
优先缓存转移矩阵、批处理或采用通过穷举验证的等价加速，不改变目标函数。
lambda=0 可使用经过测试的独立选择快捷路径。

如现有硬件无法在接受的预算内完成全部完整候选网格：
必须在 dev100 读出前登记资源性降级，开发筛选可用“零位 + 16 个非零候选”。
非零候选按加位移惩罚后的 unary 选择，保留原始索引，不用重复零位伪造 17 个不同候选。
结果标签写明 DP_pruned17，不能继续称其为完整 65 候选 DP。
在决定以“优于简单 DP”作为核心结论前，至少要完成最终参赛模型的完整候选共同校准与共同读出；否则该结论保留，不能绕过。

10.4 同分规则

节点得分精确同分时：先偏移绝对值小，再固定符号顺序和原始索引；零位自然优先。
DP 最优路径同分时采用预先确定的确定性状态顺序；不凭 GT 挑解，不用未经登记的小惩罚偷偷改变原目标。
参数配置的 cal50 Dice 在 1e-8 内同分时：优先 cal50 平均绝对位移更小的配置，再选 lambda 较小、alpha 较大者，最终按固定配置 ID。
A 层历史复原可以保留旧规则，但必须与 B 层的新规则分开记录。

10.5 边界最优与校准稳定性

若最佳 alpha/lambda 在搜索上界，记录 BOUNDARY_OPTIMUM，不自动宣布已找到最优简单基线。
如需扩展范围，只能在未读出 dev100 前更新协议，并统一应用所有对应模型，保留原网格。
默认主表不为得到理想排名无限扩大网格。
补充 cal50 按图像/病灶组 bootstrap 的选参频率，仅诊断选择稳定性，不凭 dev100 倒推某个更有利的参数。

10.6 文件与执行边界

先生成 calibration_grid.csv，再生成 chosen_config.json 并写入 SHA256。
开发读出程序验证哈希，只应用 chosen 配置，不接收“自动寻找最佳”开关。
完整 dev100 参数曲线可在主配置锁定后输出为探索性敏感性分析，不能据此替换主结果。
若以后确实据此改方法，必须新建协议，并明确该 dev100 已参与新的开发决策。

12. 机制实验：把“少动”与“选得更对”分开
======================================================================

12.1 固定位移约束敏感性

保留 _A 的完整 alpha 曲线，记录 Dice、BF1、移动比例、平均 |offset| 和 correct-to-incorrect rate。
重点看正向结果是否只存在于一个孤立 alpha 点，还是在一段保守程度内持续存在。
不同模型的同 alpha 曲线属于敏感性对照，不当作自动的公平信息范围结论。

12.2 相近移动预算对照

只对独立候选选择的 _A 族进行，避免 DP 下“移动节点数”与 alpha 的复杂关系混淆。
目标移动比例预先固定为 10%、25%、50%，分母为有轮廓图像内的有效节点，先逐图计算再宏平均。
对每个模型/种子，只用 cal50 的预测确定达到目标附近的 alpha，不用 cal50 GT 选择这个预算参数。

算法：
从 alpha=0 开始；若最大可实现移动比例低于目标，记为预算不可达，不使用负 alpha 强迫模型移动。
否则扩展非负 alpha 上界直到移动比例不超过目标，再用固定迭代次数的二分确定最接近目标且不超过目标的点。
确定性同分规则必须一致；离散跳变造成的误差保留并报告。
将该 alpha 原样应用 dev100，不能根据 dev100 的实际移动率重新调阈值。
因此实际 dev100 预算不一定完全一致，必须显示实际值；差距明显时只作近预算比较，不强称严格等预算。

主要比较：相近移动率下 TG 与 N0/T32 的修补精度、有害修改、Dice/BF1。
若 TG 的优势只在它少移动时出现，而近预算下消失，支持“保守性差异”的解释，不足以证明更好的候选消歧。

12.3 真正的局部歧义分组

不要直接把 dense 候选中排名前两位分数接近叫作歧义；它们可能只是同一宽峰的相邻采样点。
使用所有模型共享的 S64 分数，在沿法线的一维候选序列上识别局部峰。
两峰偏移距离至少 4 像素，避免把同一峰内的相邻点当成两个结构性备选。
对分离的前两峰计算公共归一化分数差。
“低间隔”阈值在 fit1800 上按该差值的第 25 百分位确定并冻结。
无两个分离峰的节点单独成组，不硬凑第二峰。
该标记只用预测信息；用于诊断，不用于改变主模型输出。

12.4 GT 可达性与消歧成功

离线评估另计算：
原位已正确：d_zero ≤ 2 像素。
当前候选可达：min_valid d ≤ 2 像素。
原位错误但候选可修：d_zero > 2 且 min_valid d ≤ 2。
局部选择失败：同种子、cal50 选定的 S64_A 选择距离 >2。
跨段修正成功：同一节点 TG 选择距离 ≤2。

重点分析“预测上存在多峰低间隔 + 候选可修 + S64 选错”的交集，同时报告各条件的独立样本数。
GT 分组仅供离线分析，不能把这种交集当作部署时可观察的输入或样本筛选规则。
节点到最近二维 GT 边界的距离是代理指标，可能遇到邻近但不同的边界段；必须结合最终掩码与可视化，不自动等于语义对应正确。

12.5 保留原始质量分组，但明确其性质

固定沿用此前区间：CNN Dice <0.60、[0.60,0.80)、[0.80,0.90)、≥0.90。
本轮可以预先登记这些区间，但它们源自前一轮事后分析，不获得新的“从未看过数据”的身份。
同时按病灶大小和候选可达性报告分布；样本过少的组只描述，不作强结论。

12.6 病例选择

固定 seed17 的预测作为病例面板，不挑最好种子；另给三种子一致改善/一致损坏标记。
从每类按预定 ΔDice 排序选 5 张，若不足则全部展示，不替换成更好看的例子。
类别：N0失败TG成功、简单DP成功TG失败、TG有害修改、所有学习模型失败而Oracle改善、候选本身不可达。
随机展示组按 ID 哈希选 10 张，避免只展示极端成功案例。
面板展示 RGB、GT、CNN、S64/N0/T32/TG、简单DP、位移与候选；GT 只用于展示和分析。

13. Oracle 与候选诊断：统一输入，但不当成性能承诺
======================================================================

13.1 必须重算同输入参照

本轮 Oracle 必须读取与本轮 CNN/G1/学习模型完全相同的 prediction、candidate points、valid mask 和重建代码。
不要继续读取 Phase1 的历史预测作为本轮 Oracle 的起点。
此前 Oracle 与当前主表 CNN 存在小的预测差别，虽不改变总体潜力判断，但不应进入正式同输入主表。[S1 第九节]

13.2 命名

使用 oracle_GT_distance 之类的明确名称。
其代价为真实边界距离加预定平滑项，是 GT 辅助可达性参照，不是可部署方法，也不是严格 Dice 上界。
不要求所有学习方法数值上永远低于这个特定 Oracle，因为它优化的不是 Dice。
不能把 Oracle 与模型的全部差距称为“Transformer 可学习空间”。

13.3 分母必须分开

报告真实边界落入搜索带的覆盖率。
报告全部预测轮廓节点中，存在距最近二维 GT 边界 ≤2 像素候选的比例。
若继续计算唯一法线交点上的候选覆盖率，单独报告有效法线率、条件分母和交点定义。
这些指标不是同一个统计量，不能直接相减。
65 个稠密候选在既定区间内取得高条件覆盖，可能是密集采样的自然结果，不是候选学习成功。

13.4 当前不改变候选空间

只有当同输入 Oracle 和分层诊断表明绝大多数剩余错误受搜索带限制时，才在下一独立协议讨论扩大半径、多步修补或重新检测。
不能在本轮主比较过程中边改候选、边改选择器，否则无法定位收益来源。

14. 指标定义与统计协议
======================================================================

14.1 分割指标

Dice = 2TP / (2TP+FP+FN)。
IoU = TP / (TP+FP+FN)。
逐图计算后宏平均；像素汇总得到的微平均另列，不能替代主表。
BF1：沿用 256×256 坐标、2 像素容差及 Fixed 边界提取方式。
HD95：沿用 max(P95(pred→GT), P95(GT→pred))；不要中途换成合并双向距离的 P95。
ASSD：沿用双向边界点距离合并后的平均。
距离单位为该评估坐标内像素，不写成毫米。
这是一套明确复用的定义，不声称所有论文均采用同一定义。
原分辨率边界评估如需增加，应另列、所有模型统一，不与 256 坐标数字混用。

空集策略沿用并测试 Fixed：双方为空时 Dice/IoU/BF1=1、距离=0；仅一方为空时重叠与边界F1=0，距离按预登记图像对角线惩罚并同时统计空预测数量。
不会静默丢弃距离无定义或很差的病例。

14.2 修补指标

Moved：预测偏移不为 0。
Improved：移动后最近 GT 边界距离比原位至少降低 1e-3 像素。
Repair precision = Improved 数 / Moved 数。
Distance increase rate = 移动后距离至少增大 1e-3 的节点数 / Moved 数。
Correct-to-incorrect rate = 原距 GT≤2、移动后距 GT>2 的节点数 / 原距 GT≤2 的节点数。
Move-on-correct rate = 原距 GT≤2 且发生移动的节点数 / 原距 GT≤2 的节点数。
后两者不同，禁止重新合并叫“错误移动率”。

成功修正率另用统一阈值定义：原位>2 且候选可达≤2 的节点中，最终≤2 的比例。
报告移动比例、所有节点平均 |offset|、仅移动节点平均 |offset|、逐图 P95 位移。
每项同时保留分子分母、逐图宏平均和节点合并统计；无分母用 NA 并记录图像数，不偷偷当成 0 或 1。
这些是节点级机制代理，不能替代最终 mask 的 Dice/BF1。

14.3 统计单位

优先患者/病灶组；无可靠分组 ID 时按图像。
同一图像的三个种子不是三个独立图像，不能把 dev100 说成 n=300。
每个种子分别报告均值；总体描述先对同图的配对差值在种子间平均，再按图像/组做 paired bootstrap。
默认 10,000 次重采样，统计随机种子 20261007。
如果多个模型共享同一冻结 CNN，只表示修补器训练随机性的重复，不代表对 CNN 训练随机性的全面稳健性。

14.4 两项主比较与多重比较

C1、C2 是预登记主比较，不根据 dev100 选择。
各自报告常规 95% 配对区间，并增加两项比较的 Bonferroni 97.5% 区间，即 bootstrap 的 1.25% 和 98.75% 分位数，作为多重比较敏感性结果。
其他模型对照、子组和参数曲线的区间都标为探索性。
bootstrap 仍有有限样本和重采样近似，不能消除重复查看开发数据、checkpoint 选择和超参数选择的偏差。

14.5 必须报告的风险与分布

平均差、中位数差、改善/下降/不变图像数。
下降超过 1 个 Dice 百分点、超过 3 个百分点的病例数量。
最差 5 张、最好 5 张、去掉最好 5 张后的均值（仅敏感性分析，不替代全体主表）。
BF1、HD95 与有害修改是否出现方向冲突。
各种子结果，而不是只写 mean±std。

14.6 效应量和精度

本计划建议将 +0.10 个 Dice 百分点（即原始 Dice +0.001）作为是否值得继续投入的工作门槛，不是临床标准、文献公认门槛或发表保证。
使用 stop/cal 的配对差值方差估计独立确认的统计精度；若预期区间宽度远大于 0.10 个百分点，提前标记该验证可能只能得到不确定结果。
不能因结果不显著而事后增删样本；不能把更多训练种子当成同等增加了独立患者数。

======================================================================
15. GO / HOLD / REDIRECT：如何决定下一步
======================================================================

以下为本项目默认的工程决策规则，正式运行前允许统一调整；读出 dev100 后不得为迁就结果改门槛。

15.1 GO：进入独立确认准备

实现、角色隔离、上游哈希、结果重算全部通过。
C1 与 C2 的三种子平均 ΔDice 均至少 +0.10 个百分点，并且各自至少两个种子为正。
同时检查主模型没有以明显更坏的边界指标换 Dice：相对各自的主比较对照（C1 对 N0_A，C2 对 BestSimple_D），默认警戒线为 BF1 下降超过 0.20 个百分点、HD95 上升超过 0.25 像素、correct-to-incorrect rate 上升超过 0.50 个百分点。
这里的警戒线不是要求有害修改率相对原 CNN 的零修改状态增加不超过 0.50 个百分点；相对原 CNN 的总体收益与损害另行完整报告。
出现警戒线时进入 HOLD，不自动因 Dice 达标放行。
至少有一项候选歧义或近移动预算诊断支持真实的选择质量改善，而非仅报告一组最优 alpha。
这些开发条件只决定是否值得独立确认，不决定论文已经成立。

15.2 HOLD：证据不足，不等于方法被否定

正向均值较小或区间很宽；强局部训练仍碰预算上限；DP 主对照未完成；选参落边界；近预算比较不可达；增益和风险冲突。
先解决对应缺口，最多进行一轮预先登记的补充确认，不继续无限搜索结构。
若主要问题是种子差异，可在方案不变时追加 101、202 两个种子，报告全部五种子，而不是替换不利种子。
追加种子提高对训练随机性的了解，但不会把 dev100 变成独立数据。

15.3 REDIRECT：按事实收窄路线

N0≈TG，且估计精度足以排除有实际价值的增益：优先考虑候选重评分，停止强调跨段模型的必要性。
S96/N0+DP≈TG：简单结构约束已很有竞争力，不能继续说它们解决不了问题。
T32≈TG：优先保留中程模型或比较其成本，不把“整条轮廓全局”作为必需条件。
收益只来自高初始 Dice 与小位移：将目标收窄为保守边界纠偏，不宣称严重漏分恢复。
所有方法都主要受候选不可达限制：另立候选/检测阶段研究，不盲目增大选择器。

这里的“≈”不能仅凭 p>0.05 判定。需要看差值区间是否足够窄，是否排除预定的实用差异门槛；区间很宽时仍归 HOLD。

15.4 不允许的成功定义

不能以“TG 比旧版有 bug 的模型好”定义成功。
不能以“TG 高于旧 8 epoch Local”定义成功。
不能以“TG 高于一个在不同数据范围上计算的 DP”定义成功。
不能以“某个 seed 或某张图很漂亮”定义成功。
不能将候选可达性的 Oracle 与最终算法混入可部署方法排名。

======================================================================
16. P5：独立确认的进入条件和流程
======================================================================

16.1 在访问 official_test600 之前检查全部上游

包括 CNN checkpoint、边界头、S64/S96、refiner、后处理、数据预处理与任何预训练来源。
公开训练脚本未列 test，只能提供旁证，不能单凭它证明实际权重从未用 test 选型。
若训练身份或历史测试暴露无法可靠核实，优先重新训练来源清楚的 CNN 与边界头，再训练选定对照；不要为了保持原来的 85.3051% 基线而继续用来源不清楚的权重作独立主证据。
B 层结果可以保留为开发对照，但不得冒充干净管线结果。

16.2 来源清楚的管线

默认使用 fit/stop 训练与选型 CNN、边界头及后续模型；cal50 继续用于候选选择后处理的校准。
如为了数据效率改用其他训练/验证分配，必须在独立测试前明确登记，并对所有模型采用相同规则。
更换 CNN 后，重新生成候选、训练后续模块、重新在允许的数据上校准；不能直接套用旧 alpha 或把旧 Oracle 当成新上界。
新管线初始 Dice 可能与旧 CNN 不同，所有关键比较必须在新管线内部配对。

16.3 冻结内容

模型族、全部 checkpoint 哈希、候选布局、预处理、alpha/lambda、重建规则、指标代码、主比较、种子列表、病例与统计规则。
写入 final_lock.json，提交代码后才生成测试预测。
以已选定的固定种子模型分别预测，报告全部种子；不选择 test 最好种子，不在看到 test 后新增集成。
如做集成，应在访问 test 前单独登记，并与匹配基线的同类集成比较。

16.4 测试不是新的调参阶段

测试脚本只能读取冻结配置，不提供网格搜索或按 test Dice 保存 best 的功能。
主结果不理想时不改参数后仍称“同一次独立测试”。如继续开发，该 test 已被暴露，需要明确改变证据级别或寻找新的未参与开发数据。
不默认额外数据集天然独立；使用新数据集前先核对相同图像、病灶或患者是否跨集合出现。

16.5 结论尺度

独立测试中保持正向实用效应、预登记区间和边界风险控制，才可以加强方法有效性主张。
若要主张两项主比较都得到独立确认，默认要求各自的预登记 97.5% 配对区间下界高于 0，平均增益达到事先锁定的实用门槛，并通过对应的风险检查；未同时达到时分别说明哪项成立、哪项仍不确定，不能笼统宣称全部假设被证实。
即使有效，是否构成论文创新仍需要另行与相关方法比较，不能由这一份消融计划自动决定。
若区间仍宽，应报告不确定；不把长期研究方向的去留归结为一次低精度测试。

20. 本轮最终应回答的一句话
======================================================================

在给足局部模型训练机会、提供同输入同容量的单节点修补器、统一保守约束与 DP 校准之后，新增跨节点通信是否仍能更准确地选择边界候选，并以可接受的成本减少错误，而不只是因为更保守所以少改坏。

答案可以是全局有效，也可以是中程已经足够，或局部重评分加简单平滑更合适。
这一轮的价值是把这些解释区分开，不是必须得到某个预设的网络排序。
